## 2. 缺陷一：随机化零模型（P0）

### 2.1 三个独立缺陷

1. **交换过程破坏简单二部图约束**。候选边检查读取的是**从未更新的**原始 `weighted` 字典，交换链因此可重复生成同一 `(company, track)` 边；`weighted2` 是 dict，重复边被静默合并 → 度配额凭空消失。
2. **边权语义被改变**。新边取 `size.get((entity, track), 1)`，交换后几乎总是 1；观察图是有权活动图（余弦相似度特征依赖权重），随机臂却近似无权。
3. **时间分布未被保留**。窗口日期**有放回**重抽样；`first_touch` 由窗口重采样日期重建，而观察快照的 `first_touch` 来自**全部历史**。结果：随机臂中**100%** 的边变成"近 12 个月新进入"，观察臂只有 10.5%。

### 2.2 量化（24 个 origin × 3 seed = 72 次抽样）

| 不变量 | 原始实现 | 修正 N1 | 修正 N2 |
|---|---|---|---|
| 两侧二元度序列一致 | **FAIL 72/72** | PASS | PASS |
| 简单图（无重复边） | 隐含 FAIL（重复边被合并） | PASS | PASS |
| 节点集合保持 | PASS（但边数减少） | PASS | PASS |
| 总事件数一致 | **FAIL 72/72** | PASS | PASS |
| 逐赛道新进入计数一致 | **FAIL 72/72** | PASS | PASS |
| 单次最多静默丢失边 | **25 条**（快照约 123–148 条） | 0 | 0 |
| 公司强度偏差（最大） | 39 个事件 | 55 | 42（已测量） |
| 赛道强度偏差（最大） | — | 62 | **0（精确）** |
| 逐赛道日期分布 TV | — | 0.54（有放回） | **0（精确）** |
| 重连边占比（均值） | 0.87 | 0.75 | 0.75 |
| 交换接受率（均值） | 未统计 | 0.61 | 0.61 |
| 确定性 | 单种子可复现 | 同种子逐位一致、异种子全不同 | 同 N1 |

最小反例：6 条边的二部图、seed=1，原始实现丢 2 条边并使度序列不一致；同一图同一 seed 下 N1/N2 全部通过（`audit_20` 的 `minimal_counterexample`）。

### 2.3 两个零模型及其无法同时保持的约束

- **N1（拓扑零模型）**：严格保持两侧二元度序列的简单二部图双边交换（动态边集 + 邻接索引）；边权按观察权重多重集置换；窗口日期有放回；`first_touch` 在逐赛道内置换（赛道级进入时间分布精确）。
- **N2（拓扑+活动量+时间）**：在 N1 之上，用整数运输问题（`scipy` 最大流）尽量同时精确保持公司强度与赛道强度；窗口日期**无放回**发牌，逐赛道日期多重集精确；`first_touch` 同 N1。

**无法同时严格保持的约束（不宣称）**：在"度序列精确 + 简单图 + 整数边权"下，**公司强度与赛道强度不能同时精确保持**——72 次真实快照中仅 1 次可行（重跑中 11/960 ≈ 1.1%）。原因是随机构造的支撑无法满足 Hall 型条件。N2 因此声明：精确保持度序列 + 赛道活动量 + 逐赛道时间分布；公司强度偏差如实报告（最大 42 个事件）。

**公司级历史在任何这类零模型下都无法保留**：这是零假设本身的含义，不是实现缺陷。依赖公司级历史的特征（`g_coentry_*`、`g_twohop_activity_decay`）在零模型下只能保持赛道级边际。此限制单独标记为 `UNRESOLVED_LIMITATION`。

## 3. 修正后 G2 重跑结果（P0）

40 次/零模型，种子 `20261104 + r`（与原实验相同），运行前固定，无自适应追加。全部 160 次抽样的不变量在运行中逐次记录并通过。

**冻结对照先验收**：B1/B2 逐行概率与原始工件**完全相同**（max |Δp| = 0.0），G1 差异 1.4e-16（浮点求和顺序）；静态路径核验确认 `_build_randomised` 只被随机化分支调用。→ 缺陷**未污染** B2/G1，主结果数值可作为 `UNCHANGED_FINDING`。

| G2 原始（有缺陷） | min/median/max = 0.06919 / 0.07411 / 0.08198 | 40/40 ≥ 真实 |

### 三条结论

1. **H4q 的"反超"不是实现缺陷造成的**：在严格保度的 N1 下、在进一步锁定赛道活动量与时间的 N2 下，仍是 40/40；缺陷只把零模型分布整体压低了约 0.0014 AP。但——
2. **H4q 的反超高度集中于单一窗口**（2025-04-01 40/40，另两窗 23/40、31/40）。因此**不能**外推为"关系网络反向有害"；它只能记为 `UNRESOLVED_LIMITATION`：机制未解决。
3. **H2q 的反超是缺陷造成的假象**：原始 30/40 → 修正后 16/40（N1）、20/40（N2），真实图回到零模型分布中央。同一缺陷在不同对数上后果不同，不能用一个说法覆盖。

**禁止的解释**：随机图 AP 更高 ≠ "随机关系有预测价值"。在有效零模型下，随机图上的图特征并不是"关系"，而是度条件化的活动量聚合量。随机化检验的正确读法是：*"真实图的排列相对其保度零模型是偏低的"*，这是关于**真实图**的陈述。

**统计力限制**：R=40 ⇒ 单侧随机化 p 的地板为 1/41 = 0.0244（双侧 0.0488）。本轮**不可能**给出更强的尾部证据；"p=0.0244" 是分辨率下限，不是精确值。

### 6.3 图特征在多大程度上只是历史的重述（科学关键）

| G1 特征 | 被 16 个 B3 特征解释的 R² | 与 B3 的最大 Spearman |
|---|---:|---:|
| `g_twohop_reach` | **0.727** | **0.891**（vs `rd_company_active_tracks_12m`） |
| `g_company_eigenvector` | **0.623** | **0.870** |
| `g_coentry_count_12m` | 0.259 | 0.384 |
| 其余 9 个 | 0.012–0.248 | ≤ 0.505 |

块平均 R² = 0.221。预测层面：只用 12 个图特征 AP = 0.0196，与"只用 4 个历史计数"的 0.0228 同量级，
远低于 B3 的 0.0751；把 G1 对 B3 残差化后再加入，AP = 0.0710，**仍低于 B3**（−0.0041）。
→ **结论：图特征作为构造 100% 来自历史；其中两个最"像结构"的特征有 62–73% 的方差是活动量的单调重述；
剩余部分没有预测价值。** 同时目标本身只有弱持续性（B2 0.0751 对基础率约 5.8× lift），
"图只是历史重述"与"历史本身也不强"两者同时成立。

### 6.4 最强的剩余风险（排序）

1. **左截断**（最大威胁）：使"首次进入"标签语义系统性偏斜（62.5% holdout 正样本是再进入）。
2. **右删失不可验证**：唯一可能制造假阴性的未知；最后窗口仅 14 天余量。
3. **14 天知识时钟假设**：唯一可能制造未来信息的未知；若真实发布延迟 > 14 天，泄漏带占 lane 0.86%–8.36%。
4. **静态 2026 分类学/实体 look-ahead**：方向使图更密（**有利于**关系假设），而本研究**没有**观察到正结果，
   因此它不能解释任何阳性发现。
5. **holdout 重叠**：推断有效性问题（pooled n 被夸大），不是泄漏。

## 10. S-028 的科学边界（必须写进摘要）

S-028 检验的是：**企业—技术共活动二部图**（同一企业在同一技术赛道上的监管活动共同出现）。

它**不是**：企业合作网络、科研机构合作网络、知识传播网络、技术许可网络、供应链网络、因果创新扩散网络。

加上 12.05% 的图事件覆盖率、51 个节点、38 个赛道的极稀疏结构、窗口内"首次"语义（62.5% holdout 正样本实为再进入）、
以及只有 14 天的知识时钟代理，本轮负结果的适用范围被**显著收窄**：

- 可以说的：**在这个特定的共活动关系代理上，没有证据表明其结构携带超出强非图基线的早期信息。**
- 不能说的："医疗技术关系网络没有价值"、"网络效应不存在"、"医疗技术创新存在新规律"。
- 也不能反向包装：H4q 的反向尾部不能被说成"我们发现了关系网络的负向规律"。

## 11. 最终判断：S-028 能否封存？

### 可以封存为「可信的探索性负结果」，条件如下

1. **主结果成立**：在预先声明的强非图基线 B2（AP 0.0751）之上，加入 12 个图特征没有改善样本外 AP
   （0.0690；company 聚类 CI [−0.0222, +0.0045]；pair 聚类 CI [−0.0335, +0.0104]；0/3 窗口排除零）。
   该结论在 bootstrap 重采样、去重、等权窗口、jackknife-t 等多种方案下方向不变（均为"无证据"）。
2. **未获支持的假设**：H1（图结构有增量信息）**未获支持**；H2（真实连接优于保度随机连接）**未获支持**
   （预注册方向为"真实更高"，实测相反或不可区分）；H3（跨主体更早信号）按停止规则从未检验；
   H4（条件性有效）**不可判定**，且在唯一 pair 口径下**没有**达到报告门槛的分层。
3. **必须同时封存的更正**：随机化实现缺陷、MDE/功效标签更正、文献纠错、holdout 独立性更正、
   "图特征=历史重述"的定量结论。
4. **必须标注的未决问题**：H4q 反向尾部的机制；左截断（"首次"语义）；右删失完整性；14 天知识时钟的真实性；
   公司级历史在零模型中的不可保留性；`HYPOTHESIS_REGISTRY.md` 的冻结内容不可核验。

### 不能封存为「确证性结论」——还缺什么

若要把 S-028 升级为**确证性**（confirmatory）结论，至少还缺：

1. **逐行 point-in-time 时钟证据**：真实首次公开日（而非 `event_date + 14d` 代理）；
2. **左截断校正**：完整历史 lane（或左截断生存模型），以恢复"首次进入"的语义；
3. **不重叠 holdout**：以 12 个月间隔取 3 个起点，或明确以单窗口为推断单元；
4. **零模型完整性的更强形式**：能在保持公司强度的同时随机化拓扑的构造（本轮证明在整数权重下不可行，
   需分数权重方案并单独论证其估计量）；
5. **独立重实现**：由第三方在不看本报告的情况下重建 G1/N1/N2 并复现数字（本轮已完成的是同仓库独立审计）。

**科学问题**：真实跨主体知识与研发关系，是否比"监管共活动代理"提供更多早期信息？

- 不预设方向：允许"真实关系不比随机关系更好"这一结果。
