## 0. 先声明证据等级与本轮性质（不许含糊）

1. 本轮**没有**真正的 point-in-time 历史抓取记录。`available_at == event_date` 对全库成立（PHOENIX-001 `04_time_semantics.json`），
   `fetched_at` 集中在 2026-10-30/31 两天。因此本轮所有结果仍然是**第 3 类：有保守公开时间约束的模拟预测**，
   不是前瞻验证。任何"预测"字样都必须带 star: `simulated prediction`。
2. **本轮是针对已知结果设计的强化验证**。PHOENIX-001 已公布 H8 的 ΔAP=+0.0379。PHOENIX-002 的假设、检验方向、
   反证手段都是在看到该结果之后设计的。因此它**不是**从未看过数据的独立预注册研究，也**不能**被描述为独立确认。
   它能提供的是：严格证伪尝试、结构偏差审计、以及"如果它成立，最少需要哪些条件同时成立"。
3. 本轮允许的结论必须落到：GO / LIMITED GO / NO-GO / INCONCLUSIVE 四类之一，按 §8 的机械规则产生，
   不允许事后调整 τ、样本、目标或模型来"救"结论。

## 2. 风险集（point-in-time eligible universe）

### 2.1 三个universe（只作为敏感性并行报告，不按结果挑选）

| universe | 赛道集合 | 用途 |
|---|---|---|
| `attr38` | 全库中曾有 **同时带 `company_key` 与 `track_id`** 的器械事件（510k/pma）的 38 个赛道 | **主分析**（与 PHOENIX-001 同一构念，便于"修复后是否仍成立"） |
| `track38` | 全库中曾有带 `track_id` 的器械事件的 38 个赛道（不要求 company 归属） | 构念效度敏感性：若效应只存在于"公司归属子样本"，则它是归属覆盖率产物 |
| `attr59` | 全库中曾有带 company 归属的任意事件的 59 个赛道（= PHOENIX-001 T-TRACK universe） | 仅用于复现与"成熟标签隔离"的对照 |

**为什么主分析是 `attr38` 而不是 `attr59`**：`attr59` 中 21 个 `t_*` 临床试验赛道在整库中**从未有过任何器械事件**，
它们对器械增长标签只能永远取 0。把"结构上不可能为正"的单元放进风险集，会人为压低基线发生率并抬高任何模型的 AP。
这是 PHOENIX-001 T-TRACK 的一个结构性缺陷（审计 B 量化）。剔除它们不是"挑样本"，而是修正一个不可预测的负例池；
但**修复后的结果必须与 59 赛道版本并列报告**，不得只报 38。

**赛道分类的后见之明**：`tracks` 表是 2026-10-30 的当前快照，赛道归属被回填到 2005 年事件。这一点**无法**从库内修复，
因此 `attr38`/`attr59` 的成员资格是**事后定义**，不是 point-in-time 可知；本轮明确把它列为不可消除限制，
并在结论中降级（不允许把基于事后赛道表的结论称为"当时可预测"）。

### 2.2 每个原点的 point-in-time 资格

对原点 q（季度）与赛道 t：

```
eligible(t, q) ⇔  t 的首个"器械事件特征季度" f(t) 满足  q − f(t) + 1 ≥ 8
                  （即 q 季度末可公开知道的器械历史至少 8 个季度）
```

只使用该赛道自己过去的事件，不使用任何未来事件、也不使用全库未来信息决定某条记录是否进入风险集。
行从 `f(t)` 开始（之前不存在该赛道作为器械赛道的行）。资格与标签所需的最短历史一致（trailing-8Q 可定义）。

### 2.3 A / B 两种现象必须分开研究

| 层 | 定义 | 标签 |
|---|---|---|
| **A 已活跃赛道的持续增长** | `trail8_total ≥ 1`（过去 8 季有器械事件） | 主目标 Y1 |
| **B 曾活跃但当前沉默赛道的新增长** | `trail8_total == 0` 且该赛道过去曾有器械事件 | 只能用 Y4（emergence） |

**严禁**把 A 的结果解释为 B 的结果。B 在 Y1 下是退化的（0 ≥ 1.5×0 恒真），因此 Y1 的 B 层结果只作为"目标定义缺陷"的证据报告。

## 3. 标签成熟时间与训练隔离（本轮第一个修复对象）

### 3.1 可执行断言

标签在原点 q 覆盖未来窗口 `(q, q+4]`，最后一刻为 `end(q+4)`。设声明的标签公布延迟 `L` 天：

```
label_observable_quarter(q, L) = q + 4 + ceil(L / 91)
purge_quarters(L)              = 4 + ceil(L / 91) + 1
train_latest_origin(q_test, L) = q_test − purge_quarters(L)
```

测试原点 `q_test` 的决策时刻为 `end(q_test)`，因此保守要求标签在 `end(q_test − 1)` 前已可观测：

```
断言：  label_observable_quarter(q_train, L) ≤ q_test_first − 1   对所有训练行成立
等价：  q_train ≤ q_test_first − purge_quarters(L)
```

其中 `q_test_first` 取该折**最早**的测试原点（比"用折末最大测试原点"更保守）。

| L | ceil(L/91) | purge 季度 | 含义 |
|---|---|---|---|
| 0 | 0 | 5 | 无公布延迟（乐观） |
| **90** | **1** | **6** | **头条假设**（与特征滞后一致） |
| 180 | 2 | 7 | 压力测试 |

`v1_naive` 折规则（训练到测试年前一季）**不满足**上述断言；`purged` 满足。两者并列报告，差值即成熟标签泄漏的影响。
`selftest.py` 断言 purged 违规行数 = 0，并记录 naive 的违规行数与"训练标签依赖测试期事件"的比例。

### 3.2 为什么这算泄漏而不是"只是依赖"

训练行 q 的标签窗口若越过测试原点，该标签的取值就部分由**测试期内发生的事件**决定（例：2013Q4 的训练标签由 2014Q1–Q4 事件决定，
而 2014 正是测试年）。模型系数因此含测试期结果信息。必须排除，不能仅凭"特征已截断"宣称无泄漏。

### 3.3 其他时间处理

- 前瞻窗口重叠：相邻原点共享 3/4 个未来季度。**头条对比使用全部原点 + 以 track 为聚类的 bootstrap**；
  另报 Q1-only 非重叠原点、每年一行的敏感性。
- 2025 折只有 2025Q1–Q2 两个原点（标签窗口到 2026Q2，仍在数据内）。
- PHOENIX-001 的 `build_joint_panel` 在 2025Q2 截断后才算标签，导致 2024Q3–2025Q2 四个原点被静默丢弃。
  v2 在完整网格上算标签（`mode='v2'`），恢复这些原点；`mode='v1like'` 只用于复现对照。

## 4. 预测目标

器械事件计数口径随 universe：`attr*` 计 company 归属器械事件，`track*` 计全部带 track 的器械事件。

| 目标 | 定义（事件时钟） | 角色 |
|---|---|---|
| **Y1 `growth_ratio`** | `fwd4_total ≥ 3 且 fwd4_mean ≥ 1.5 × trail8_mean` | **主目标，与 PHOENIX-001 完全一致，不得替换** |
| Y2 `abs_increase` | `fwd4_total > trail8_total / 2`（绝对数量高于过去年化水平） | 替代目标（弱分母依赖） |
| Y3 `new_plateau` | `fwd4_total ≥ 3 且 fwd4_mean ≥ 1.5 × max(trail8_mean, trail12_mean, trail16_mean)` | 替代目标（相对长历史的新台阶） |
| Y4 `dormant_emergence` | `trail8_total == 0 且 fwd4_total ≥ 3` | 仅 B 层；只在沉默赛道子集定义 |

`fwd4_*` = `q+1..q+4` 的事件计数；`trailW_*` = `q−W+1..q`（含 q）的滚动统计。
若某替代目标结果更好，**不得**替换主目标；只能作为独立敏感性报告。
**若 Y1 的正样本中 `trail8_total ≤ 2` 者超过 50%**，则判定 Y1 在本数据上不可解释为"显著增长"（§8 的 artifact gate）。

## 5. 基线与候选模型（同一批可评价行上比较）

| arm | 定义 |
|---|---|
| `M0_prevalence` | 训练折发生率（常数） |
| `M1_persistence` | L2 logistic：器械历史的 10 个尾随特征 + exposure（= PHOENIX-001 B1） |
| `M2_ma_level` | L2 logistic：4/8 季移动平均与历史水平 |
| `M3_trend` | L2 logistic：12 季对数线性斜率 + 趋势外推分数 + 加速度 |
| **`M4_h8_growth`** | `M1` + 7 个 SciTrends 式增长特征（与 PHOENIX-001 H8 定义相同） |
| `M5_full_regularised` | `M1` + 增长特征 + 全来源历史，L2 `C=0.5` |
| `M6_hgb` | HistGradientBoosting（`max_iter=150`, `depth≤4`, `lr=0.06`）参考非线性模型 |
| `M7_mean_reversion` | L2 logistic：仅水平类特征（均值回归通道对照） |

模型选择不做超参搜索（除上述固定设置）；不因模型更复杂而优待。所有模型在**相同训练行、相同测试行**上拟合/评分。

主要对比：`M4_h8_growth − M1_persistence`（预注册的 H8 增量），以及 `M4` 对每个其它基线；
每条对比都是同一批行上的配对差。

## 6. 评价指标

主指标：**Average Precision (PR-AUC)**、**ΔAP 及配对 95% 置信区间**（以 `track_id` 为聚类的 bootstrap，B=1000，seed=20261109）。
同时必报：

- 发生率、有效正样本数、可评价行数、可评价赛道数、有效折数；
- ROC-AUC、Brier、校准斜率（`y ~ a + b·score` 的 b）；
- Precision@5%/10%/20%、Recall@5%/10%/20%、lift；
- **固定告警预算**：每季度 top-10 的 precision、命中正样本数、每季度误报数（可解释的误报负担）；
- 按年份、按 trailing 活动量分层、按公司归属覆盖率分层的 AP 与 ΔAP；
- 预测提前量：原点 q 的预测覆盖 q+1..q+4，因此操作上可用的提前量为 1–4 个季度（固定，不由模型学到）。

## 7. 统计规则与推断

1. **时间顺序严格隔离**：唯一划分是 expanding-window walk-forward，测试年 2014–2025；训练集严格在测试年之前并满足 §3 的 purge。
   不使用随机划分、shuffle、k-fold。
2. **训练标签必须在预测时成熟**（§3 断言）。
3. **前瞻窗口重叠**：以 track 聚类 bootstrap；另报非重叠敏感性。
4. **重抽样**：cluster bootstrap over `track_id`（赛道是相关性单位）。配对对比用**同一组重抽样索引**同时计算两个 arm。
5. **多重检验**：主目标族 = {Y1(主), Y2, Y3, Y4}，在 L090/attr38/purged 配置下做 Holm 校正并报告；
   其余全部检验（各 lag、各 universe、各分层、反证）标记为 secondary/exploratory，不参与 GO/NO-GO 判定，
   但必须全部报告（包括与主结论矛盾的）。
6. **样本量**：有效正样本 < 100 时不得下 GO/LIMITED GO；CI 宽度 > 2τ 时判定为 INCONCLUSIVE（无法分辨 τ 与 0）。
7. **不把单特征 |corr| < 0.80 当作无泄漏证明**：泄漏用 §3 的可执行断言检验，相关性筛查只作辅助。
8. **不把可复现当作真实**：同一脚本可复现一个错误结论是可能的；因此必须有 §9 的反证与构造机理分析。
9. **不把模拟预测称为前瞻验证**（§0）。
10. **预注册最小实际有意义增益 τ = 0.03 AP**（PHOENIX-001 的 H8 阈值，沿用，不因本轮结果调整）。
    报告必须同时给出：点估计、CI、以及 CI 是否足以支持 τ（CI 下界 > 0 且上界 ≥ τ 才有"支持"的可能）。

## 8. 判定门槛（机械规则，按顺序执行）

设主配置 P0 = `attr38` + `v2` + `Y1` + feature L090 + label L090 + `purged` 折。

| 门 | 条件 |
|---|---|
| **G1** | 主对比 ΔAP ≥ 0.03 |
| **G1b** | 主对比配对 bootstrap 95% CI 下界 > 0 |
| **G2** | 交叉 universe：`track38` 上 ΔAP ≥ 0.02（构念稳健性） |
| **G3** | 赛道内时间打乱安慰剂：单侧 p < 0.05（观测 ΔAP 超出安慰剂零分布 95 分位） |
| **G4** | 活跃层（`trail8_total ≥ 1`）ΔAP ≥ 0.02 |
| **G5** | 有效正样本 ≥ 100 |
| **G6** | CI 上界 ≥ τ（即 τ **未被排除**；若 CI 上界 < τ 则 τ 被排除，直接判 NO-GO） |
| **G7（artifact gate）** | Y1 正样本中 `trail8_total ≤ 2` 的比例 ≤ 50% |

判定映射：

- **GO**：G1 ∧ G1b ∧ G2 ∧ G3 ∧ G4 ∧ G5 ∧ G7 全部成立。
- **LIMITED GO**：G1 ∧ G1b 成立，但 G2/G3/G4/G7 至少一个不成立（结论收缩到成立的那部分条件，并明确写出失败门）。
- **NO-GO**：**G6 不成立**（CI 上界 < τ，τ 被排除）；或 0 < ΔAP < τ 且 CI 下界 > 0（统计上为正但低于实际意义门槛）；
  或 placebo 显示效应完全由打乱不改变的结构（如 G3 失败且 G7 失败）。
- **INCONCLUSIVE**：G5 不成立，或 CI 同时跨 0 与 τ（无法分辨），或主对比非有限。

**任何反证实验发现系统性问题时，不得通过改阈值、换模型、换目标来救结论。** 只能如实降级并写清机理。

## 9. 反证与安慰剂（全部预注册，全部必报）

| 编号 | 检验 | 预期（用于证伪） |
|---|---|---|
| A1 | 赛道内部按时间打乱 H8 增长特征（200 次置换，重训模型） | 若增益来自时间对齐信息，观测 ΔAP 应超出零分布 95 分位；否则说明增益与"何时"无关 |
| A2 | 季度内跨赛道打乱增长特征（100 次；PHOENIX-001 的安慰剂） | 应塌回 ≈0（验证"接线"而非"信息"） |
| A3 | 增长特征整体后移 8 季（t−8） | 通用活动度信号会存活；近期增长信号应显著衰减 |
| A4 | 剔除低基数（`trail8_total ≤ 2`）；活跃层/沉默层分别报告 | 若 ΔAP 只在低基数层存在，则目标是"任意 3 事件"而非增长 |
| A5 | 按公司归属覆盖率分层（≥50% vs <50%），并报告 24 个 <50% 赛道 | 若效应只在低归属赛道，说明是归属覆盖率趋势产物 |
| A6 | 去除完全重复的监管记录后重算标签（dedupe key = kind+track+date+product_code+company） | 若效应依赖重复记录膨胀，应缩小 |
| A7 | 训练截止/窗口敏感性：首测试年 2012/2014/2016；8 年滚动训练窗 | 结论不应只在某一切割点成立 |
| A8 | 负对照目标：用器械增长特征预测**试验事件**增长 | 若同样有效，说明只是"赛道整体活动度"，不是器械技术增长 |
| A9 | 按年份、按活动量分层、按 data coverage 分组的同向性 | 方向应一致；不一致要逐项解释 |

`M7_mean_reversion` 用于把"均值回归通道"单独建模：若 H8 的增量在 M7 之上消失，则增益可由水平/回归解释。

## 10. 停止规则与偏差记录

- 若数据库 SHA-256 不匹配、自检失败、或某配置有效正样本 < 30：**停止该配置并标 NOT TESTABLE**，不得用新数据补。
- 出现设计缺陷（例如某个目标无法定义、某 universe 无正样本）时：记录在 `results/summary.json → deviations`，
  不得静默替换。判定仍按 §8 执行。
- 禁止：实时采集、云 GPU、购买数据、训练大模型、新增研究工具、改前端、重构主架构、修改 PHOENIX-001 冻结文件。
- 计算预算：CPU only，单机；全流程 < 30 分钟。

用独立代码复算 AP/ΔAP/CI 与判定门槛，不得读取训练代码的中间变量。

## 12. 本轮不能证明的事

- 不能证明"实时前瞻预测能力"（无 point-in-time 抓取、单快照）。
- 不能证明赛道归属在历史当时可知（track 表为当前快照回填）。
- 不能证明 PMA/510(k) 比例代表技术"进步"；它只是监管门槛构念的代理。
- 不能把 H1（历史持续性）的高 AP 解释为"发现了新技术"，它首先说明"原来常申报的将来也常申报"。
- 不能把 H7 的半合成变化点基准当作真实技术转向检测能力。
- 不能把本轮结论外推到器械以外的领域或 2004 年以前。
