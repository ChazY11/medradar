# PHOENIX-001 — 科研差距与创新机会

## 别人已经完成什么

- SciTrends：出版主题的长期增长、Review/Original Research、专利与文本特征预测。
- PubTrends：论文聚类、引用网络与主题描述。
- NIH iSearch：跨源科研突破识别与历史案例展示，但实现未充分公开。
- The Lens：论文—专利实体和引用连接。
- PTNS：专利引用轨迹的时序图神经网络，但代码和原始数据未公开。
- FDA AI 纵向研究：专科集中度、趋势、企业类型与小样本稳健性。
- 商业平台：跨源聚合、企业/产品标准化、赛道与生命周期展示、竞品监控。

MedRadar 不需要再做一套“功能更多”的展示层。真正缺口是：这些能力在时间约束下能否变成可证伪的早期信号。

## 哪些方法不能直接迁移

- Review/Original Research 比例没有天然监管等价物，不能硬把 510(k)/PMA 当作同义分类。
- 论文和专利引用网络依赖公开延迟与回填快照；当前引用图不能当历史特征。
- PTNS 的专利轨迹目标不是监管里程碑，且代码、Incopat 数据和 MedRadar 专利行均缺失。
- 商业平台的覆盖率、AI 归一和预测宣传不是科学验证；闭源分类体系也不能自由复制。
- 采购金额不是收入或研发，首次公开时间不明时不能进入历史增益实验。

## MedRadar 最重要的数据限制

按优先级排序：

1. **知识时钟**：历史公开时间是估计值，真实 observed-as-of 样本极少，所有当前预测只能是类别 3。
2. **实体和分类版本**：缺少 alias、规则、置信度、所有权日期和 taxonomy_version；并购与后建赛道映射会改写历史。
3. **链接覆盖与选择偏差**：S-028 图中只有 12.1% 的事件通道同时具备公司与赛道，且不是行业随机样本。
4. **独立血缘不可复核**：当前环境没有原始 SQLite，设备/申报/试验及其派生副本无法重新去重。
5. **跨源目标缺口**：无成熟试验→FDA 目标，专利为 0 行，采购缺首次公开时间。
6. **左截断与正样本稀疏**：首次只代表窗口内首次/再进入；entry 子组常只有 1—3 个正样本。
7. **前瞻队列尚未形成**：没有足够成熟且独立的 category-4 样本。

## 实验支持、否定与未决

- **支持**：H1，企业—赛道的历史监管活动持续性很强。
- **当前协议内否定**：H9，多源融合没有稳定超过最强单源。
- **阻断**：H5、H6。
- **未决**：H2、H3、H4、H7、H8、H10。联合模型不能替代单特征消融，GNN 未运行，变化检测缺少正验证例。

最有价值的负结果是：continuation 中 pair 基线已解释绝大部分提升。后续研究不能只增加模型复杂度，必须证明增量信息。

## 值得继续研究的跨源信号

1. **临床试验首次公开时间**：有潜力提供监管决策前信号，但必须先解决 sponsor 归并、试验血缘和合格里程碑映射。
2. **论文年度计数**：当前增量小且不稳定，只适合做强正则化消融，不适合继续堆特征。
3. **专利**：具有理论提前量，但当前为 0 行。先解决公开时间、同族去重和许可，暂不作为近期主线。
4. **采购**：先重建首次公开时间和覆盖偏差，否则停止预测用途。

## 新的可证伪科学问题

- **Q1：条件持续性。** 修正所有权和分类版本后，pair persistence 在哪些年份、企业和赛道仍然优于公司/赛道基线？其衰减是否可预测？
- **Q2：试验增量。** 试验首次公开是否在控制 pair persistence 后，对未来 12 个月合格 FDA 里程碑增加至少预先设定 δ 的 AP，并保持可接受误报负担？
- **Q3：集中度—扩散关系。** 控制赛道活动量后，HHI 的变化是否仍能解释下一期参与企业数或有效企业数？
- **Q4：最小充分模型。** 哪一个最简特征集能在所有滚动窗口稳定优于 pair persistence，而不是只在最终原点获胜？
- **Q5：公开时间误差。** decision_date+14d 与真实首次公开时间的偏差分布多大？什么信号在该误差下仍保持排序稳定？
