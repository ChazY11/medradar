# MedRadar 2.0 — 用户指南

面向**不需要工程背景**的使用者。5 分钟了解如何研究一家企业、比较竞争对手、分析技术趋势、追溯证据和提问。

## 0. 启动

在仓库根目录运行：

```bash
python -m medradar web --port 8787
```

看到 `MedRadar 2.0 MVP -> http://127.0.0.1:8787` 后，用浏览器打开该地址。

> 首次启动需要几秒钟预热数据缓存。若提示找不到研究数据库，需先运行一次 `python -m medradar run`
> （已有数据快照的机器不需要）。产品不需要任何 API Key，也不需要联网。

界面右上角始终显示**数据截止日**与数据版本。所有页面顶部都会说明当前使用的时间窗与数据来源。

## 1. 总览（Overview）

你会看到：

- 五家深度支持企业、事件总量、技术赛道数量、赛道映射覆盖率；
- "结论 → 指标 → 事件 → 原始来源"的证据链说明；
- 8 大技术领域的最新活动概览；
- 产品的硬性限制（美国数据、记录数≠产品数、当前没有经验证的预测）。

## 2. 研究一家公司（Companies）

1. 点击导航 **企业情报**；
2. 在五家企业卡片中点击一家（例如**迈瑞医疗**），或搜索任意企业名；
3. 企业主页包含：
   - **基本信息**：名称、代码、总部、业务简述（人工整理，会标注）；
   - **关键指标**：数据覆盖期内的审批记录、召回、试验，及最近窗口对比；
   - **研究结论卡片**：每条结论都写明变化量、对比时段、行业对照、份额变化、置信度与局限；
   - **点击"查看证据"**：展开该结论使用的记录（最近窗口 / 前一窗口），可继续打开单条记录；
   - **技术布局**：各赛道的记录数、占比、首次进入时间；
   - **趋势图**：可按 3 / 5 / 10 年切换，悬停查看精确数值；
   - **数据覆盖**：每个数据源的实际起止日期和条数；
   - **里程碑**：首次 510(k)、首次 PMA、首次临床试验、首次召回、首次 8-K；
   - **限制说明**：例如"美国 FDA 记录不等于全球活动"。

> 迈瑞与德尔格不在仓库原有企业名册中，它们的企业归属来自逐条精确名称匹配，页面会标记
> "待人工复核"。这不会改变记录本身，但你在引用数字时应当知道这一点。

## 3. 比较竞争对手（Compare）

1. 点击导航 **企业对比**；
2. 选择 2–5 家企业（默认已选 Medtronic 与 Philips；点击企业标签可切换）；
3. 选择指标（审批记录 / 510(k) / PMA / 召回 / 试验 / 8-K）与时间窗；
4. 查看：
   - 并排趋势图；
   - 每条赛道的记录数、企业内占比、**专业化指数**（location quotient，>1 表示该企业在该赛道的占比高于全行业）；
   - **可比性警告**：监管路径差异、数据覆盖差异、低样本量等。警告不会被隐藏。

> 不要用 FDA 记录数量给企业创新能力排名。不同企业的产品组合、监管路径与披露习惯不同，
> 页面会主动提示这些差异；这也是比较功能的核心价值。

## 4. 分析技术趋势（Technology Radar）

1. 点击 **技术雷达**；
2. 浏览 8 大领域：患者监护、医学影像、超声、呼吸与通气、体外诊断、医疗 AI、心血管器械、外科技术；
3. 点击任一领域中的赛道（例如**呼吸与麻醉**）：
   - 季度审批活动趋势图（悬停看数值，点击柱子进入证据列表）；
   - 企业构成与份额；
   - 窗口内首次进入该赛道的企业；
   - **统计探测信号**：相对前 8 个季度的 z 分数异常，带方法说明与"不证明真实技术变化"的提示；
   - 最近公开记录列表，可直接打开原始证据。

## 5. 追溯研究结论（Evidence Explorer）

任何结论卡片的"查看证据"都会展示：

1. 结论使用的**记录数**（按同一口径重新计算）；
2. 最近窗口与前一个窗口的**事件列表**；
3. 单条事件的详情：事件日期、公开日期、数据来源、产品代码、赛道、企业归属方式；
4. **原始来源链接**（只有数据库中存在链接时才显示；否则明确写"该记录没有可用的原始链接"）。

你也可以直接打开 **证据浏览器**，按企业、赛道、指标、来源、时间与关键词检索全部记录。
关键词为原文匹配（标题/申请人/摘要，通常为英文）；中文企业名或赛道名请使用筛选器。

## 6. 使用研究助手（Research Analyst）

1. 点击 **研究助手**；
2. 输入自然语言问题，例如：
   - "过去五年，迈瑞的超声产品发生了什么变化？"
   - "Medtronic 和 Philips 在患者监护领域有哪些区别？"
   - "哪些企业在呼吸支持设备领域的公开活动增加？"
   - "GE HealthCare 近十年有哪些值得注意的技术变化？"
   - "过去三年哪些医疗技术领域出现了明显加速？"
3. 回答会展示：
   - **它如何理解你的问题**（企业、赛道、时间窗）；
   - 结论、数据表、方法与口径；
   - 可点击的证据记录；
   - 局限；
   - 建议的后续问题。

> 研究助手是**确定性检索引擎**，不是自由发挥的大模型：没有 API Key 也能用；它不会编造查询。
> 如果问题超出数据范围（例如企业战略、营收、全球市场份额、因果关系），它会直接说明无法回答，
> 并告诉你它可以回答什么。

## 7. 研究实验室（Research Lab）

查看项目现有研究：Cycle 43 全历史早期预警基准、五家企业早期信号研究、预测注册表、变化探测。
每个项目都标注：

- 研究问题、数据、方法、状态（支持 / 不确定 / 负面 / blocked）；
- 关键数字与来源；
- 复现命令与材料路径；
- 明确边界：AI 预标注不是人工真值；`research/full-history-v1` 分支**未合并**，只做只读引用；
- 当前**没有**经过前瞻验证的预测。

## 8. 常见问题

**为什么同一家企业的数字在不同页面略有不同？**
不同页面使用的时间窗不同（例如 3 年 vs 5 年），或指标口径不同（审批 vs 召回 vs 试验）。
每个数字旁边都写明窗口与指标。

**为什么迈瑞/德尔格的美国记录这么少？**
因为这些数据是美国 FDA 记录，只反映其在美国的监管活动，不代表全球业务。

**为什么没有"预测未来"功能？**
现有研究显示早期信号只有边际效果，尚未通过实用性与前瞻校准验证。产品只展示观察到的变化
与统计探测信号，不展示确定性未来结论。详见研究实验室。

**数据多久更新？**
由研究管线（`python -m medradar run`）更新；页面顶部显示数据截止日。产品本身不抓取网络数据。

遇到问题？查看 [`PRODUCT_ARCHITECTURE.md`](PRODUCT_ARCHITECTURE.md) 的数据口径说明，
或直接打开证据浏览器核对原始记录。
