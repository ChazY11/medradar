**必须公开的面板构造细节（不是定义改动）**：`phoenix_common.build_joint_panel()` 在返回前就把面板裁到 `origin_end`，而 `add_forward_target()` 由调用方在之后才调用——因此**最后 4 个原点会得到 `y = NaN`**，`03_harness_smoke.json` 的 62,732 有标签行正是这个调用顺序的产物，2025 折会变成空折。
本实验让 harness 先构建到 `origin_end + 4`（它的前瞻窗口行），**先贴标签、后裁剪**；尾部特征在裁剪后计算，故取值完全不变（`selftest.py` 的 A2 用真实面板证明了 `max_abs_feature_diff = 0.0`）。**口径未改**，并且：

> **冻结数字复现检查**：把本面板限制到 `03_harness_smoke.json` 能够打标签的原点（≤ 2024Q2），得到 **n = 62,732 / n_pos = 12,517 / prevalence = 0.199531**，与冻结报告**逐位一致**（`cache/panel_meta.json` → `frozen_subset_check.matches_03_harness_smoke = true`，三个滞后场景均 MATCH）。因此本节面板与既验证面板是同一个任务，只是补回了被裁掉的 4 个可计算标签的原点。

**原点到标签的时钟分离**（`results/leakage_investigation.json`）：特征时钟 = `available_at + 90d`。对 200 个随机单元 × 2010Q1–2025Q2 共 **10,428 个单元-季度**逐个核对"特征能看到的最新事件的 `event_date`"与"标签窗口开启时刻"的最小间隔 = **91 天 > 0**。即任何进入特征的试验/器械事件都严格早于标签窗口，不存在时钟重叠。

"company 的赛道集合 vs track 的 company 集合"的字面 Jaccard 在二部图上无定义，故实现为同类型重叠：`|T_c ∩ U_r| / |T_c ∪ U_r|`，`U_r` = 赛道 r 内活跃企业的赛道并集，并在报告中按此命名（`net_jaccard_company_track_peers`）。

**模型选择冻结**：特征集、臂、超参数、样本、滞后场景**全部在看结果之前写定**；本报告没有做任何 holdout 调参。所有 bootstrap 用 `seed=20261108`，B=1000，聚类 = `company_key`（89 个簇）；配对差值使用同一批行。

## 4. H1 — 持续性：单元自身监管历史是否优于发生率基线？

- **预注册定义**：`AP(B1 持续性) − AP(B0 发生率)`，holdout；支持条件 `ΔAP ≥ 0.05` **且** 配对 p<0.05 **且** ≥9/12 折同向。
- **样本**：判定样本 `holdout_q1` n=4,221 / n_pos=690 / prevalence=0.1635；`headline_q1` n=11,613 / n_pos=2,045 / prevalence=0.1761。
- **主对比**：`AP(B1) − AP(B0) = +0.7240`，95% CI [+0.6837, +0.7647]，配对聚类 bootstrap p = 0.000（p<0.002），**12/12 折同向**（每折 ΔAP 0.681–0.754）。
- 三个滞后场景：L000 +0.7341、L090 +0.7240、L180 +0.7161 → **结论不依赖滞后假设**。

| 样本 | 臂 | AP [95% CI] |
|---|---|---|
| holdout_q1 | B0 | 0.1656 [0.1211, 0.2079] |
| holdout_q1 | B1 | 0.8896 [0.8419, 0.9235] |
| headline_q1 | B0 / B1 | 0.1853 [0.1387, 0.2324] / 0.8903 [0.8446, 0.9224] |

**描述统计（证据等级 D/R，`results/audit_cell.json` → `H1_descriptives`）**
- 单元季度计数序列的 Spearman 自相关（逐单元计算，按企业聚类 bootstrap）：lag1 = **0.0963** [0.0623, 0.1352]（407 个非常数序列 / 51 个企业簇，46.2% 为正）；lag2 = 0.1056 [0.0758, 0.1360]；lag4 = **0.0954** [0.0641, 0.1307]。**季度级自相关很弱**——平均意义上没有"季度到季度"的平滑惯性。
- 但活跃状态迁移极强：`P(active_{t+1}|active_t) = 0.6422` vs 速率匹配置换零模型 **0.5848（q95 = 0.5898）**，经验 p = 0.005（200 次置换的最小可分辨值），相对无条件活跃率 0.0851 的 lift = **7.55**；`P(active_t | inactive_{t+1}) = 0.0335`。
- 近期活动分层：`P(y|0 个近 4 季事件) = 0.0522`（53,328 行）、`P(y|1–2) = 0.5479`（6,649 行）、`P(y|≥3) = 0.9540`（7,107 行）。**H1 的全部预测力来自这个近 4 季活动分层**，不是季度自相关。
- **稳定性**：3 年块（Q1 非重叠）AP(B1) = 0.888 / 0.883 / 0.910 / 0.883，AP(B0) = 0.192 / 0.189 / 0.172 / 0.168 → 每块 ΔAP = +0.696 / +0.694 / +0.738 / +0.715；top-10 企业 AP(B1) 0.611–0.982，无任一企业反号。完整表见 §11。
- **泄漏审计**：L1 特征/标签相关筛查（75 个特征）无 |r|>0.80；L2 未来信息 PASS（`max_abs_feature_diff = 0.0`）；AP>0.9 触发的专项调查见 §10 末尾，结论为"持续性，不是泄漏"。
- **判定：SUPPORTED**（S 级；描述统计 D/R）。附带说明：AP 的高绝对值中有一部分来自 §5 的总体结构（永远为负的试验赛道单元），把样本限制到"曾有器械事件的单元"后，ΔAP 仍有 **+0.4703** [+0.4257, +0.5142]（§9）。

## 5. H2 — 加速：活动加速是否领先后续更密集的活动？

- **预注册定义**：`AP(含加速特征模型) − AP(仅水平特征模型)`，holdout，**单侧**；支持条件 `ΔAP ≥ 0.02` 且 p<0.05 且 ≥9/12 折同向。
  实现上两个臂是**唯一只差 `*_accel` 列**的同一 L2 逻辑回归（B1 vs B2_levels，特征数 31 vs 28），因此对比无混杂。
- **样本**：`holdout_q1` n=4,221 / n_pos=690 / prevalence=0.1635；`headline_q1` n=11,613 / 2,045 / 0.1761。

| 样本 | 臂 | AP [95% CI] |
|---|---|---|
| holdout_q1 | B2_levels（仅水平） | 0.8890 [0.8408, 0.9234] |
| holdout_q1 | B1_persistence（含加速） | 0.8896 [0.8419, 0.9235] |
| headline_q1 | B2 / B1 | 0.8901 [0.8442, 0.9222] / 0.8903 [0.8446, 0.9224] |

- **主对比**：ΔAP = **+0.0006** [−0.0007, +0.0022]，单侧 p = **0.181**（双侧 0.362），**6/12 折**同向 → 不满足任一条件。
- 三滞后：L000 +0.0001（p=0.482，7/12）、L090 +0.0006、L180 **−0.0007**（p=0.768，3/12）。符号本身不稳定。

**描述统计（`H2_descriptives`）**：按协议定义"加速事件"= `f_n_device_accel > 0` 且近 4 季自身器械计数 ≥2，L090 下共 **1,641** 个（占 2.45% 行）。
- 后续 4 季率：加速事件行 **0.8550** [0.8175, 0.8820]，其余行 **0.1803** [0.1352, 0.2260] → 率比 **4.74** [3.82, 6.27]（企业聚类 bootstrap）；置换检验 p = 0.005（最小可分辨值）。三滞后率比 4.69 / 4.74 / 4.78，稳定。
- **但把活动水平固定住之后结论反转**：在同一"近 4 季 ≥2"门限内，`P(y|加速且高活动) = 0.8550` 反而**低于** `P(y|不加速且高活动) = 0.9063`。也就是说 4.74 倍的率比**完全由活动水平解释**，加速项在水平之上给出的是负增量。这与模型对比（ΔAP≈0）一致。
- **领先时间**：从中位 **1 个季度**（IQR 1–3）到后续首个器械事件；1,641 个信号事件中 82 个（5.0%）右删失（到数据末尾仍无后续事件），报告中未插补。
- **稳定性**：3 年块 AP(B2_levels) = 0.888 / 0.883 / 0.908 / 0.882，AP(B1_persistence) = 0.888 / 0.883 / 0.910 / 0.883 → 每块 |ΔAP| ≤ 0.002（详见 §11）。
- **泄漏审计**：两臂只差 `*_accel` 列（由尾随窗口构造），L1 筛查无 |r|>0.80、L2 未来信息 PASS；加速特征本身也是未来无关的（A2 覆盖 `f_n_*_accel`）。
- **判定：NOT SUPPORTED**（S 级；描述 D/R）。这是协议预期可能出现的负面结果，未调整任何判定标准。

## 6. H4 — 跨企业上下文：所属赛道特征是否在自身历史之外提供信息？

- **预注册定义**：`AP(自身特征 + 赛道上下文特征) − AP(仅自身特征 B1)`，holdout；支持条件 `ΔAP ≥ 0.03` 且 p<0.05 且 ≥9/12 折同向；**若 ΔAP < 0.01，明确写"H4 未获支持"**。
  由于预注册对比两侧特征集宽度不同（B5_context 68 维 vs B1 31 维），另报**嵌套对比** `B5_context − B5_self`（同一 L2、仅加 17 个上下文列）作为未校正的探索性检验。
- **样本**：`holdout_q1` n=4,221 / n_pos=690 / prevalence=0.1635。

| 臂 | AP [95% CI] `holdout_q1` | AP [95% CI] `headline_q1` |
|---|---|---|
| B1_persistence（仅自身） | 0.8896 [0.8419, 0.9235] | 0.8903 [0.8446, 0.9224] |
| B5_self（全部自身特征） | 0.8973 [0.8505, 0.9296] | 0.8979 [0.8542, 0.9284] |
| B5_context（+赛道上下文） | **0.8976** [0.8504, 0.9292] | **0.8988** [0.8553, 0.9288] |

- **主对比（预注册）**：ΔAP = **+0.0080** [+0.0037, +0.0138]，p = **0.002**，12/12 折同向 → **ΔAP < 0.01，落入协议的反证条件，H4 未获支持**。
- **嵌套对比（未校正、探索性）**：`B5_context − B5_self` = **+0.0003** [−0.0023, +0.0029]，p = 0.862；同一嵌套对比在 `headline_q1` 为 +0.0009（p=0.126）、在 `all_origins` 为 +0.0004（p=0.590）、在 `holdout_all` 为 −0.0002（p=0.874）。**赛道上下文本身没有增量信息**；上面那 0.008 来自"特征更多"而不是"赛道信息"。
- 三滞后（主对比）：L000 +0.0026（p=0.150，7/12）、L090 +0.0080、L180 +0.0116（p<0.002，12/12）——全部低于 0.03，且随滞后变长而变大（上下文特征在更长滞后下更"陈旧"但仍含同赛道活动水平，属预期方向）。
- 结构旁证（§9）：把样本限制到 411 个"曾有器械事件"的单元后，主对比降到 **+0.0023**（p=0.146）、`headline_q1` 为 +0.0027（p<0.002）——**再次确认上下文增量的主体是"识别试验赛道单元"这一总体结构效应，而非赛道内信息**。
- **稳定性**：3 年块 AP(B5_context) = 0.892 / 0.895 / 0.917 / 0.891，AP(B1) = 0.888 / 0.883 / 0.910 / 0.883 → 每块 ΔAP = +0.004 / +0.012 / +0.007 / +0.008，**无一块接近 0.03**（详见 §11）。
- **泄漏审计**：`ctx_*` 只聚合当季及以前的赛道活动（尾随窗口），L1 无 |r|>0.80、L2 PASS；`share_of_context` 与 `ctx_*` 均在 A2 的 81 列不变性检查范围内。
- **判定：NOT SUPPORTED**（S 级）。

## 7. H5 — 临床试验增量：自身试验历史是否为器械里程碑提供增量信息？

- **预注册定义**：`AP(自身器械历史 + 自身试验历史) − AP(仅自身器械历史)`，holdout；支持条件 `ΔAP ≥ 0.02` 且 p<0.05。
  协议同时要求写明：试验与器械许可之间**没有**公开的设备级一一对应键，故只能是"赛道内共变"，不是"试验→许可"因果链。本报告进一步发现**连"赛道内共变"都不成立**（见下）。
- **样本**：`holdout_q1` n=4,221 / n_pos=690 / prevalence=0.1635。

| 臂 | AP [95% CI] `holdout_q1` | AP [95% CI] `headline_q1` |
|---|---|---|
| B1_persistence（仅器械） | 0.8896 [0.8419, 0.9235] | 0.8903 [0.8446, 0.9224] |
| B1_plus_trial（+试验） | **0.8977** [0.8511, 0.9296] | **0.8981** [0.8545, 0.9286] |

- **主对比**：ΔAP = **+0.0082** [+0.0054, +0.0118]，p = 0.000（p<0.002），12/12 折同向。ΔAP 未达 0.02，判定 **NOT SUPPORTED**。
- 三滞后：L000 +0.0035、L090 +0.0082、L180 +0.0104，同样全部不达标。

**决定性结构事实（`results/sensitivity_device_cells.json` → `structural_facts`）**：数据库里 **试验事件使用 21 个独立赛道（`t_*`），器械事件使用 38 个赛道，二者 track_id 交集 = 0**。
因此：
1. 任何 `(company_key, t_*)` 单元**永远不可能**满足 510k/pma 标签 → 552 个单元的每一行都是结构性负样本；
2. 在 411 个"曾有器械事件"的单元里，试验特征恒为 0 → **H5 在单元内没有任何可识别性**（不是"信号弱"，而是"不存在"）；
3. 上面那 +0.0082 的增量，只能来自模型学会"试验赛道单元 ⇒ 没有器械里程碑"这一总体标记。限制到 411 个器械可用单元后，H5 主对比塌缩为 **+0.0014** [+0.0004, +0.0031]（`holdout_q1`）。
4. 领先时间不可测：7,984 个"试验活跃单元-季度"中，同一单元此后**从未**出现器械事件（100% 右删失）——因为试验赛道单元不含器械事件。协议要求的"信号→目标事件中位季度数"在本数据上 **NOT TESTABLE**。
- **稳定性**：3 年块 AP(B1_plus_trial) = 0.895 / 0.893 / 0.915 / 0.891，AP(B1) = 0.888 / 0.883 / 0.910 / 0.883 → 每块 ΔAP = +0.007 / +0.010 / +0.005 / +0.008（详见 §11），**每块都低于 0.02 门槛**。
- **泄漏审计**：试验特征同样只来自尾随窗口；L1 无 |r|>0.80、L2 PASS。真正的风险不是泄漏而是本节所述的结构性不可识别。
- **判定：NOT SUPPORTED，且结构性不可识别**（S 级；"试验→器械里程碑"的增量信息在本数据上是不可检验项，不是弱效应）。

## 8. H10 — 复杂模型 / 网络特征是否真的优于简单 L2 逻辑回归？

- **预注册定义**：`AP(B6/B7) − AP(B5)`，holdout；支持条件 `ΔAP ≥ 0.03` 且 p<0.05 且 ≥9/12 折同向 **且** holdout 校准斜率不比 B5 差（差距 ≤ 0.2）；若 ΔAP < 0.01，明确写"复杂模型未获支持"。主对比指定为 B7−B5（B7 为协议 §4 的最强臂），B6−B5 作为次级（未校正）。
- **样本**：`holdout_q1` n=4,221 / n_pos=690 / prevalence=0.1635。

| 臂 | AP [95% CI] `holdout_q1` | AP [95% CI] `headline_q1` |
|---|---|---|
| B5_context（全特征 L2） | 0.8976 [0.8504, 0.9292] | 0.8988 [0.8553, 0.9288] |
| B6_hgb | 0.9090 [0.8672, 0.9375] | 0.9112 [0.8713, 0.9379] |
| B7_hgb_net | **0.9099** [0.8682, 0.9382] | **0.9125** [0.8722, 0.9387] |

- **主对比 B7−B5**：ΔAP = **+0.0123** [+0.0066, +0.0194]，p = 0.000（p<0.002），12/12 折同向。
- **次级 B6−B5**：ΔAP = **+0.0114** [+0.0057, +0.0185]，p = 0.000（未校正、探索性）。
- **校准条件**：`holdout_all` 上 B5_context 校准斜率 0.991、B7_hgb_net 0.996，差距 **0.006 ≤ 0.2** → 校准条件满足。
- 但 ΔAP = 0.0123 **远低于 0.03 支持线**（只相当于约 1.2 个 AP 点），高于协议的 0.01 反证线 → **判定：INCONCLUSIVE**。可读的实质结论：**复杂模型确实比简单 L2 略好、且 12/12 折稳定，但增益幅度只有预注册"实质改进"门槛的 40%，在告警预算 P@10% 上仅从 0.954 提到 0.966（提升 1.2 个百分点）。按协议"不得因失望而调整标准"，这不是支持；从工程角度它也不构成保留复杂模型的理由。**
- 三滞后：L000 +0.0091（NOT SUPPORTED，低于反证线）、L090 +0.0123、L180 +0.0111（p=0.006）——从未接近 0.03。
- 网络特征自身贡献：`holdout_q1` 上 B6→B7 的 ΔAP 仅为 **+0.0009**（0.9090→0.9099；`headline_q1` 上为 +0.0013），即**二部图特征几乎不贡献**；复杂模型的增益主要来自 HGB 的非线性/交互，而不是网络结构。
- 结构旁证（§9）：限制到器械可用单元后，L090 `holdout_q1` 的 B7−B5 = **+0.0077** [+0.0031, +0.0142]（p<0.002），B6−B5 = +0.0067（p=0.008）——同一结论。
- **稳定性**：3 年块 AP(B7) = 0.908 / 0.913 / 0.923 / 0.906，AP(B5_context) = 0.892 / 0.895 / 0.917 / 0.891 → ΔAP = +0.016 / +0.018 / +0.006 / +0.015，**每块都低于 0.03**（详见 §11）。
- **泄漏审计**：B7 的网络块经 A2 真实验证（当季活跃子图归一化，截断未来数据后 PageRank 完全不变）；L1 无 |r|>0.80（75 个特征最大 |r| = 0.705）。
- **判定：INCONCLUSIVE**（S 级；实质为负面结果：未达到实质性改进）。

## 12. 局限（直说）

1. **89 家公司 ≠ 医疗器械行业**。T-CELL 的标签宇宙要求 510k/pma 同时带 `company_key` 与 `track_id`；分析窗口内 **68.27% 的器械事件（79,745/116,804）落在这个交集之外**（510k 缺键比例 88.05%，pma 37.84%）。全部结论只对这本 89 家注册企业的 411 个器械可用单元成立，不能外推到行业。
2. **赛道分类学的人为二分裂**。试验数据用 21 个 `t_*` 赛道、器械数据用 38 个器械赛道，交集为 0。后果：(a) 552 个单元结构性永远为负，把全样本 prevalence 从 0.476 人为稀释到 0.197，并抬高所有臂的 AP；(b) **H5 在单元内不可识别**，协议想要的"试验→器械里程碑"在本数据上是不可检验项。这是数据设计问题，任何"试验领先器械"的结论在 medradar 上都无法成立。
3. **滞后场景是人工注入的，不是真实公开时滞**。`available_at ≡ event_date`，单快照。本报告最高证据等级 S，**绝不是 P**。三档滞后下 H1/H2 结论稳定，H4/H5/H10 的 ΔAP 在 0.003–0.012 之间随滞后移动，说明这些小效应本身也不稳健。
4. **面板补回 4 个尾部原点**（见 §1）。冻结数字在 ≤2024Q2 子集上逐位复现，但"67,084 行全部有标签"与 `03_harness_smoke.json` 的"62,732 有标签"不同，原因是 harness 的裁剪顺序，而不是任务定义。任何跨团队合并数字时须注意这两套 n。
5. **4 季前瞻窗口重叠**。头条用非重叠 Q1 原点；`all_origins` 仅作敏感性且依赖结构已知（相邻原点共享 3/4 窗口）。
6. **特征包含原点当季事件**（harness 约定：在原点的**季末**决策）。若真实决策发生在季度初，特征会含 0–3 个月未来信息——这是协议层面的假设，本报告无法检验。
7. **上下文特征的分母随时间变化**：`ctx_*` 聚合的是"当季已存在的单元"，早期季度会低估赛道总量。这只会削弱 H4，而 H4 本来就不达标。
8. **H10 的检验力**：holdout_q1 只有 4 个原点、4,221 行、690 正样本、89 个聚类簇；bootstrap p 已到 0.002 下限，因此"p<0.002"不等于"效应大"。ΔAP 的 95% CI 上界（+0.0194）仍远低于 0.03 门槛，所以 INCONCLUSIVE 不是"检验力不足"的托辞——数据已经足以排除 0.03。
9. **510k→PMA 双计**：823 个同公司同 product_code 的 510k→PMA 对（≤730 天）会让同一产品在两个窗口各记一次正样本；未做去重（协议未要求），只计量上界。
10. **网络特征定义**：使用当季活跃子图做 PageRank 归一化（`net_jaccard` 为同类型重叠代理），与"89×59 固定全集"不同；两种定义都无未来信息，但数值不可直接比较。
11. **`calibration_slope` 的 harness 实现**混用 `np.cov`（ddof=1）与 `np.var`（ddof=0），会放大约 n/(n−1)；在 n>4,000 时 <0.05%，不影响 H10 的 0.2 校准门槛（自测中已按 harness 自身算术断言，并记录该实现细节）。
