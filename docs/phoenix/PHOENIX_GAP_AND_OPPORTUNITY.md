# PHOENIX-001 — 科研差距与创新机会报告

> 本文件回答任务书第十节 E 的七个问题，并给出 F 的路线图。
> 所有数字来自本轮实际运行的产物，每个都指向证据文件。**没有数字的地方写"不可检验"或"未知"，不编造。**

---

## 0. 一句话总结

**别人已经把"用什么特征预测科研/技术增长"这件事做得相当充分；MedRadar 的真实差距不在模型，而在数据：没有真正的 point-in-time 时钟，企业实体有 86.6% 缺失，比赛道归属按当前配置回填到 2005 年。本轮在承认这三条限制的前提下，得到了一个清晰的结论——**

> **在这批数据上，能稳定预测未来的只有"历史持续性"本身；加速度、跨公司上下文、试验增量、图网络与梯度提升，全部只带来 <0.013 的 AP 增量。唯一值得留下的外部方法思想是 SciTrends 式的"归一化增长特征"（ΔAP +0.038，且经安慰剂检验）。**

## 1. 哪些方法别人已经完成？（不需要我们重做）

| 已被完成的能力 | 谁做的 | 我们的判断 |
|---|---|---|
| 科研主题时间序列预测 + 严格时间验证 | SciTrends（Heliyon 2023） | **已复现其 Table 1 到末位数字**，方法已理解。不需要重做，只需适配 |
| 论文—专利关联 + 引用结构 + 时滞度量 | The Lens（Nat Biotechnol 2018） | 方法公开、数据商业。我们**没有**相应语料，不重做 |
| 专利引用轨迹预测 + 时序网络快照评价 | PTNS（Sci Rep 2024） | 方法公开、代码与数据不可得。不重做 |
| 论文主题聚类 + 引用网络 + 新兴领域 | PubTrends（JetBrains） | Apache-2.0 可复用，但**它本身不含任何预测目标与精度指标** |
| 技术赛道集中度（HHI）+ 扩散 + 显著性与小样本稳健性 | FDA AI 器械纵向研究（JMIR/PMC） | **已公式级复现**（Wilson/z 检验/CA/HHI），可直接作为工具 |
| 变化点检测（PELT / CUSUM）及其评价 | 公开算法文献 | 自实现并做了匹配误报预算的基准，**比固定阈值高约 12.5 pp** |
| "突破"的递归聚类定义 | NIH iSearch | **核心主张未能核实**（产品页 403；可及材料只描述单层 R-MCL）。不重做，也不宣称 |

**结论**：方法层面 MedRadar 不需要从头发明。**真正的空白在"把方法用在医疗技术监管历史上并给出可信的、有约束的评价"这件事本身。**

## 3. MedRadar 当前最重要的数据限制是什么？（按严重度排序，全部有数字）

### 限制 1（最严重）：不存在真正的 point-in-time 时钟

```
available_at == published_at == event_date   对所有 375,378 条事件成立（差值恒为 0 天）
fetched_at 全部落在 2026-10-30 / 2026-10-31 两天
```

**后果**：
- 无法区分"当时就知道的"与"后来才知道的"，**任何回测都可能包含后来回填的信息**。
- 本轮被迫注入人为滞后（L000/L090/L180）。结论在 L090 与 L000 下差异很小（H1 的 ΔAP 从 0.724 → 0.734 → 0.716），说明**这些特定结论对滞后不敏感**——但这是运气好，不是系统保证了 point-in-time。
- **本轮不产生"第 4 类：独立前瞻验证的预测"**，结构性不可能。

**这是唯一一条无法用现有数据修复的限制。** 修复只能靠**从现在开始持续按 as-of 记录**（见路线图 R1）。

### 限制 2：企业实体大面积缺失

| kind | `company_key` 为空 |
|---|---:|
| 510k | **86.64%** |
| 8k_catalyst | 93.52% |
| device_recall | 51.38% |
| drug_approval | 61.15% |
| pma | 34.51% |
| trial | 30.36% |

**后果**：所有"企业×赛道"结论只建立在 13.4% 的 510(k) 上 → **非随机缺失的选择偏差**。89 家企业是精选大厂，**幸存者偏差**无法排除。

**已尝试修复**：候选模块 RAEA 把 510(k) 覆盖率从 13.36% 提到 15.68%（+8,914 条归属），但**仍未度量其对下游结论的影响**，因此**未晋级为正式集成**。

### 限制 3：赛道归属时代错位

赛道配置是**当前版本**回填到 2005 年的事件。一个 2025 年定义的赛道（如 `ep_pfa` 脉冲场消融）被应用到 2005 年的产品码上。
**后果**：早期"赛道活动"部分是把今天的分类知识投射到过去 → **潜在前视**。本轮以敏感性分析处理（单列 L7，并按 3 年区块报告稳定性），不假装修好。

### 限制 4：单快照 + 无前瞻登记

库里没有任何 2026-10-30 之后的数据；也没有预先注册的前瞻观测登记表。
**后果**：无法做"预测 → 等待 → 验证"的闭环。本轮所有远期结论最高只能到"模拟预测"。

### 限制 5：8-K 完全无法归因；试验与器械赛道**结构性不相交**

- `8k_catalyst` 事件中 **0 / 20,976** 带 `track_id`（`drug_approval` 亦 0 / 2,678）。
- 更严重的是：**临床试验事件全部落在 21 个 `t_*` 药品类赛道，器械事件落在 38 个器械赛道，两者共享 0 个 track_id。**

**后果**：
1. H9 预注册的 5 臂设计实际只跑了 4 臂（在**任何拟合之前**就已确定并记录）。
2. **H5（试验→器械里程碑）在单元内根本没有可识别性**——不是"没信号"，而是**这个数据模型里不存在这条边**。它必须被标记为 **NOT TESTABLE**，不能报成"不支持"。
3. 552 个单元格因此结构性永远为负，抬高所有臂的 AP（见 §5.0）。

**这是数据模型问题，不是分析问题**：要检验 H5，必须先建立 `trial → product_code` 或 `trial → 器械赛道` 的映射，而当前 schema 无法表达。

### 限制 6：左截断与样本重复

- 12.80% 的单元-季度行 `exposure_q < 8`（已做排除敏感性：结论不变）。
- 同 企业+赛道+产品码+日期 的重复组 9,240 个（计数，未删除）。
- 前瞻窗口高度重叠（已改为头条只用非重叠原点）。

## 4. 哪些历史规律经实验支持？

**前提**：头条为 L090 滞后场景、非重叠原点（每年 Q1）、聚类 bootstrap（B=1000）、raw p 由我统一做 Holm 校正。证据等级见每条标注。

| 结论 | 数字 | 证据等级 | 稳健性 |
|---|---|---|---|
| **H1：企业的赛道历史活动有显著持续性** | 单元级 holdout（n=4,221，正样本 690，发生率 16.35%）：ΔAP = **+0.7240**，95% CI [0.6837, 0.7647]，p<0.001，**12/12 折方向一致** | **S** | L000/L090/L180 三档全部 SUPPORTED（+0.734 / +0.724 / +0.716） |
| **H8：SciTrends 式归一化增长特征可迁移到器械事件数据** | 赛道级（n=2,443，正样本 155，发生率 6.34%）：ΔAP = **+0.0379**，CI [+0.0115, +0.0618]，p=0.004 | **S** | L000/L180 均成立；4 个 3 年区块全部成立；仅 Q1 样本成立；holdout 成立；**安慰剂（特征跨赛道打乱）塌回 0.119 ≈ B1 的 0.123** |
| **H7：变化点检测优于固定阈值（匹配误报预算下）** | 24,000 条半合成序列：CUSUM 0.714 / PELT 0.714 vs 固定阈值 0.588 → **+12.5 pp**，p<0.001 / 0.002 | **方法研究**（非 D/R/S 历史证据） | 在 4.5%–4.8%/季 的等误报预算下；**在协议字面阈值下固定阈值反而更好，但代价是 10.6%/季误报** |

**关于 H1 的解读必须谨慎**：ΔAP = +0.724 看起来极大，但这**主要是基线（B0 常数预测器）太弱**造成的——在 16% 发生率下，常数预测器的 AP 就等于发生率本身。**正确的读法是"持续性远优于随机"，而不是"模型很强"。** 绝对水平见 §5 的 AP 表。

### 5.0 一个必须记录的取样陷阱：552 个"结构性永远为负"的单元

`T-CELL` 面板里有 **552 个单元在构造上永远不可能出现器械事件**（它们的赛道是药品类 `t_*`，器械事件不会落在那里）。把大量"容易排对的负样本"放进分母，会**系统性抬高所有臂的 AP**。

证据：把样本限制在 **411 个"器械可产出单元"**（发生率从 16.3% 跳到 **47.6%**）后：
- H1 仍成立：ΔAP 从 +0.7240 降到 **+0.4703**（方向不变，量级下降合理）
- **H4 从 +0.0080 塌到 +0.0023**
- **H5 从 +0.0082 塌到 +0.0014**

→ **H4/H5 的表观增益几乎全部来自那 552 个结构性负单元，不是真实的预测信息。** 这条敏感性分析比主表更有信息量，必须与主表一起引用。

### 5.0.1 高 AP 的泄漏排查结论：不是泄漏

头条 AP ≈ 0.89（B1）触发了协议自定的">0.9 可疑"规则，已专门排查：
- 任何"特征可见事件"与标签窗口之间**至少间隔 91 天**
- 300/300 个标签由原始事件**独立重算且完全一致**
- 单特征与标签的最大 |r| = **0.705**（告警线 0.80，疑似泄漏线 0.95）

→ 高 AP 来自**持续性本身**：11.8% 的单元-季度在原点季度活跃，这些行承载 51.9% 的正样本，其中 P(y)=0.865 vs 0.107。**结论：不是泄漏，是数据结构。**

### 5.1 本轮最重要的科学发现（跨全部实验）

> **"复杂化"在这一数据上不产生价值。**
> 十个假设里，唯一成立的路径是**更简单**的那一类：历史持续性（H1）与归一化增长特征（H8）。而"更强的模型"（H10）、"更多的数据源"（H9）、"更多的上下文"（H4）、"更精细的动态"（H2）全部只带来 **<0.013 的 AP 增量**，且**没有一个达到预注册的实质阈值**。

这不是"我们的模型不够好"，而是**信号本身的形状**：医疗技术监管活动是一个高持续性、低加速性的过程。想靠更复杂的模型榨出更多信息，方向错了。

### 5.2 一个必须记录的反例（"显著但不重要"的陷阱）

H4、H5、H10 的 95% CI **全部排除零**，p 值都 <0.005，12/12 折方向一致。如果只报 p 值，它们看起来"都成立"。
但它们的效应量是 **0.008 / 0.008 / 0.012**，全部低于预注册阈值。
**这正是预注册的作用**：判定规则在实验前写死，避免了"因为显著所以宣布胜利"。

## 7. 我们能提出什么新的、可证伪的科学问题？

以下问题**都能用现有数据检验**，且**都能被证伪**。每条注明所需数据与预期成本。

### Q1（最有价值）：监管活动的"持续性"本身是否是**赛道属性**而非**企业属性**？
**可证伪表述**：在控制了赛道固定效应后，企业历史对自身未来活动的预测增量是否消失？
**检验**：混合效应 / 赛道内去均值后的 ΔAP。
**数据**：本轮面板即可。**成本：低（1 天）。**
**为什么重要**：若持续性主要是赛道属性，那么情报产品的原子单位应该是**赛道**而不是企业——这会改变整个产品架构。

### Q2：是否存在"**监管密度周期**"——同一赛道内 510(k) 提交呈周期性聚集？
**可证伪表述**：赛道季度序列的谱密度在 2–8 季频段是否显著高于白噪声？
**检验**：Lomb-Scargle / 谱分析 + 置换零模型。
**数据**：本轮 59 条赛道序列。**成本：低（2 天）。**
**为什么重要**：若有周期，可做季节性调整，H1/H8 的估计会更准；若无，说明"爆发"是外生事件驱动。

### Q3：**PMA/510(k) 比率**的变化是否领先赛道整体的技术复杂度上升？
**可证伪表述**：赛道内 `PMA/(PMA+510k)` 比率的 4 季变化，是否预测下一 4 季该赛道产品码的**新颖度**（首次出现产品码占比）上升？
**检验**：Granger 式滞后相关 + 严格时间切分的 ΔAP。
**数据**：本轮数据即可（`product_codes` 表有 7,097 个码）。**成本：中（3–5 天）。**
**为什么重要**：这是 SciTrends "review/original 比例"在本域的**唯一合法类比**，也是本项目已有的构念。

### Q4：变化点检测的**分层使用**是否优于任何单一检测器？
**可证伪表述**：按赛道规模切换检测器（小赛道 → 固定阈值；大赛道 → CUSUM/PELT）的组合策略，在匹配误报预算下的检出率是否高于任何单一检测器 ≥5 pp？
**检验**：复用 H7 的 24,000 条半合成序列，加一个分层策略臂。
**数据**：已全部就绪。**成本：很低（半天）。**
**为什么重要**：H7 已发现固定阈值在小赛道更好（.652 vs .560）、CUSUM/PELT 在大会道更好（.859 vs .532）。这是**已被数据指出但尚未利用**的机会。

### Q5：**前瞻登记**能否把第 3 类证据升级为第 4 类？
**可证伪表述**：从现在起按 as-of 记录未来 N 个月的监管事件，其预测表现是否与回测估计一致？
**数据**：**必须新增采集**（本轮不做）。**成本：高（需持续运行 6–12 个月，且需运维）。**
**为什么重要**：这是**唯一**能把 MedRadar 的结论从"模拟"升级为"前瞻验证"的路径。没有它，永远停在第三类。

## 8. 本轮没有回答的问题（诚实边界）

1. **专利作为领先指标是否适用于医疗器械？** —— 无专利数据，**不可检验**。
2. **论文产出是否领先器械许可？** —— 无出版物表（仅有弱通道），**未检验**。
3. **中国 NMPA 数据能否用于跨国扩散研究？** —— 库里 NMPA 为空/demo，**未检验**。
4. **复杂模型在更大样本下是否会胜出？** —— 本轮 89 家企业 + 1,116 单元；若实体覆盖提升到 50%，结论可能改变。**未检验**。
5. **RAEA 新增的 8,914 条归属会改变哪些既有结论？** —— **未度量**，因此该模块未晋级。
6. **H7 的结论在真实变点上是否成立？** —— 半合成基准只证明检测器性质，**不证明真实历史存在可检出变点**。

## 9. 结论：MedRadar 应该相信什么、不应该相信什么

**应该相信（有实验支持，且经得起时间假设与安慰剂检验）**
- 企业的赛道监管活动具有强持续性 → 这是所有预测的**下限基线**。
- 归一化增长特征（SciTrends 式）能带来**小而真实**的增量（ΔAP +0.038）。
- 在匹配误报预算下，CUSUM/PELT 的检出能力**确实**优于固定阈值约 12.5 pp。

**不应相信（本轮明确否定或无法支持）**
- "加速度"能提前预警。
- "跨公司网络特征"能显著提升预测。
- "多源融合"优于最强单源。
- "更复杂的模型"能带来实质提升。
- 任何"我们的 AP 比某论文高"的跨研究比较——**风险集不同则不可比**（见复现报告 §3）。

**必须永远记住的前提**
> 在补上 point-in-time 采集之前，MedRadar 的一切"预测"都只是**受约束的回测**。声称它是"前瞻预测"就是造假。
