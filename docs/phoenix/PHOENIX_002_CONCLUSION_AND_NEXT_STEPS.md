## D. 科研结论

### D.1 判定：**NO-GO**

按冻结协议 §8 的机械规则（`results/verdict.json`）：

| 门 | 判定 | 数字 |
|---|---|---|
| G1 主对比 ΔAP ≥ τ=0.03 | **FAIL** | +0.0294 |
| G1b 95% CI 下界 > 0 | PASS | [+0.0082, +0.0573] |
| G2 交叉构念（全部带 track 器械事件）ΔAP ≥ 0.02 | **FAIL** | +0.0123 [−0.0788, +0.1107] |
| G3 赛道内时间打乱安慰剂 p < 0.05 | **FAIL** | p = 0.0846（零分布均值 +0.0171） |
| G4 活跃层 ΔAP ≥ 0.02 | PASS | +0.0227 |
| G5 有效正样本 ≥ 100 | PASS | 176 |
| G6 CI 上界 ≥ τ（否则 τ 被排除） | PASS | 0.0573 ≥ 0.03 |
| G7 低基数正样本占比 ≤ 50% | PASS | 4.5% |

**结论文字**：H8 的增量在更严格条件下**低于预注册的实际意义门槛**，且未通过交叉构念与安慰剂两项独立反证；
其增量在去除重复监管记录后基本消失（+0.0048，p=0.508），其"增长"特征块本身（4 个归一化增长率）不携带增量
（+0.0027，p=0.476）。因此 **NO-GO：H8 的效果主要由数据结构（结构负例 / 公司归属采样 / 重复记录）
与目标定义（相对自身历史的比率标签的几何性质）解释，不构成"增长特征预示未来增长"的证据。**
判定不是 INCONCLUSIVE：主对比的 CI 上界 0.057 ≥ τ，即数据无法排除"存在中等效应"，
但按预注册规则（点估计低于门槛、且多项独立反证失败）不得判 GO/LIMITED GO；
也不能判"完全无关联"——正确表述是"**没有达到实际意义门槛、且现有证据不支持其作为早期信号**"。

### D.3 对 MedRadar 的直接含义（不夸大）

1. **不要再把 H8 当作产品叙事的核心。** 它在本轮最严格口径下低于门槛，且其机理是标签几何 + 数据质量。
2. **PHOENIX-001 的负数结果仍然成立**（H3/H6/H9/H10 无实质增量；H5 不可检验），但 PHOENIX-001 中
   "H8 SUPPORTED" 与 "H1 强基线" 两个正面表述都应被本轮的修正口径替换。
3. **真正可用的稳健事实只有两条**：
   - 赛道/单元的活动水平有短期持续性（但增益很小，38 赛道口径下 +0.018 AP，CI 含 0）；
   - 简单趋势基线（斜率+趋势外推+加速度）比任何"增长特征"模型都更有效（+0.065 AP over 训练发生率）。
   换言之，"原来常申报的将来也常申报；最近在加速的会继续加速一段时间"——仅此而已。
4. **当前数据不允许声称"早期技术信号"**：单快照、无 as-of 历史、赛道分类事后回填、公司归属随时间漂移、
   15.9% 重复监管记录、2024Q3 之后样本极少。这些是**数据基础**问题，不是模型问题。

## E. 下一步科学研究建议（只从已验证结果出发）

### E.1 是否真的找到值得研究的历史规律？

**有一个弱规律，但不是"技术增长"规律。** 它是由三件事组成的混合体：
(1) 活动水平/趋势的短期持续性；(2) 相对自身历史的比率标签带来的几何可预测性；
(3) 公司归属采样与重复记录造成的数据结构。前两者是可预期的统计现象，第三者是不可接受的偏差。
**没有证据表明存在"技术赛道的增长特征可以预示未来增长"这一规律。**

### E.2 该规律与普通时间序列持续性有什么不同？

**在本数据上，没有可检验的不同。** 证据：
- H8 的增量在纯噪声（无趋势、无记忆）上可被同一管线复制（+0.0373，40/40 为正）；
- 独立验证者用自己的实现得到同类零分布：均值 +0.0469（sd 0.0240），观测 +0.0294 位于 25 分位（上尾 p=0.76）；
- 把相对比率目标换成绝对水平目标（`fwd4_total ≥ 3` / `≥1`）后，ΔAP = 0.0000；
- H8 的 4 个"增长率"特征只贡献 +0.0027，增量来自 `slope12`（对数斜率）与 `volatility8`（离散度/水平）——
  它们是水平变换，不是增长信息；
- 简单趋势模型 M3 的 AP 高于 H8；
- 非重叠原点（仅 Q1）上主分析 ΔAP 只有 +0.0160（52 个正样本，p=0.36），即全原点的显著性依赖重叠窗口的重复暴露。

### E.3 该规律在哪些类型的技术赛道上成立？

只在**活动量最高的一层**（trailing 8Q ≥ 13 事件，1,353/1,723 行、119/176 正样本）有 +0.0234 的名义增量，
但该层内方向不稳定（2019、2022 年为负），且该层正是大类赛道（cardiac_rhythm、structural_heart 等），
其"增长"主要由 89 家注册企业的归属覆盖变化驱动。**在低活动赛道、沉默赛道、`t_*` 试验赛道上无可用结论**
（Y4 仅 3 个正样本）。

### E.4 能否找到可解释的失败案例？

能，且已在审计 C 中量化：
- **按赛道**：`neurovascular`（per-track ΔAP −0.240）、`insulin_delivery`（−0.099）、`ophthalmology`（−0.057）
  是 H8 明显更差的赛道；
- **按年份**：2019 折 ΔAP −0.051、2022 折 −0.021；
- **按活动层**：6–12 事件层 ΔAP −0.019（22 个正样本）；
- **按归属覆盖率**：高归属（≥50%）赛道 ΔAP **−0.0195**，低归属赛道 +0.0300 —— 效应只在低归属（高噪声）处存在。
- **去重后**：ΔAP 从 +0.0294 掉到 +0.0048，正样本 176→160。这是最解释性的失败：**它预测的"增长"部分是重复记录**。

### E.5 是否有必要开展更复杂的技术转向研究？

**没有必要先做更复杂的模型/变化点研究。** 理由：
- 本轮最复杂的模型（HGB）也没有优于简单趋势（−0.0088）；
- 半合成变化点基准（H7）不能作为真实技术转向检测能力的证据（任务书 §6 已明确）；
- 在当前数据基础上，任何更复杂的模型都只能拟合同样的标签几何与数据缺陷，风险是制造更精致的伪信号。
**在数据基础修好之前，"更复杂的技术转向研究"不是科学的下一步。**

### E.6 如果当前数据不足，究竟缺哪一种信息（不是泛泛"加数据"）

按优先级排列，每条都对应本轮一个具体的不可修复缺陷：

1. **As-of / point-in-time 历史快照**（而不是 2026-10-30 的单快照回填）。
   这是唯一能让"前瞻验证"成立的前提；当前 `available_at == event_date`、`fetched_at` 只有两天。
2. **赛道分类的历史版本 + per-event 归属时间戳**（当前 60 个赛道与 7,097 个产品代码全部 `updated_at=2026-10-30`，
   18/38 个器械赛道"首发于 1976Q3"是回填痕迹）。没有它，任何"赛道首次出现/转向"的结论都不可检验。
3. **申报人→企业的历史实体解析（含并购/更名/别名）与归属置信度**。
   当前 v1 只保留 20.8% 的事件；归属率随年份 18.5%→36.7%→29.7%、随赛道 0.24%→93.8%。
   需要的不是"更多事件"，而是"每个事件是否/何时能归到企业"的可信记录。
4. **产品级实体解析 / 去重键（canonical regulatory milestone key）**。
   当前 15.9% 的器械事件是完全重复记录；去重后 H8 的增量消失。没有 canonical key，标签计数不可靠。
5. **绝对、可解释的结果定义**（而不是"相对自身过去 1.5 倍"的比率）。
   例如：新产品代码首次获批、PMA 新适应症、first-in-class 认定等具有临床/监管意义的离散事件；
   以及与之配套的**专利/论文/临床试验阶段**数据（当前库内没有，PHOENIX-001 已标 BLOCKED）。
6. **前瞻观测登记（prospective registry）**：MedRadar 已有 Research Lab 的前瞻观测登记机制（见仓库历史）；
   若要在 3–5 年后回答"增长特征是否预示未来"，唯一可靠的方法是**现在冻结预测、将来用真实新增记录评分**。

**明确不建议**：继续在同一份单快照、同一套事后赛道表、同一组 89 家企业上增加模型复杂度或调参；
那只会重复本轮已经量化过的伪信号。

## F. 什么结果会让我们改变结论（可证伪的后续条件）

如果未来满足以下**全部**条件，H8 类假设值得重新评估：

1. 用 as-of 快照重建，训练标签成熟时间可验证；
2. 赛道活动度用"全部带 track 事件"且去重后计算，不依赖 89 家企业归属；
3. 在**绝对/离散结果定义**（而非比率标签）上，增长特征对基线有 ≥0.03 的增量且 95% CI 下界 > 0.02；
4. 赛道内时间打乱安慰剂 p < 0.01（而不是 0.085）；
5. 在低归属与高归属层**方向一致**（当前是 +0.030 vs −0.020）；
6. 至少 3 个独立时间块方向一致，且不依赖 2–10 个正样本的薄赛道。

在这些条件满足之前，MedRadar 应把资源投向**数据可信度**（E.6 第 1–5 项）与**前瞻登记**，
而不是更复杂的预测模型。
