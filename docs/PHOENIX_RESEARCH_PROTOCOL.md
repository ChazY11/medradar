# PHOENIX-001 — H1—H10 冻结研究协议

冻结时间：2026-11-06T00:28:00Z。机器可读定义：`experiments/phoenix_001/hypotheses.json`。

## 证据分层

1. 描述性规律。
2. 历史回顾性时间关系。
3. 使用保守公开时间代理的模拟预测。
4. 独立前瞻验证。

本轮预测比较全部为 **类别 3**，因为监管事件使用 `decision_date+14d` 的估计公开时间。`first_seen_at` 是批量回填日期，不能证明当时已知。变化检测的新颖性分析为类别 2，FDA 论文聚合复算为类别 1。没有类别 4 结果。

## 共同时间边界

- 主队列使用季度滚动原点，训练标签必须在下一评估原点前成熟。
- 最终 untouched holdouts：2025-04-01、2025-07-01、2025-10-01。
- continuation：6,701 个成熟 pair-origin 样本、3,833 条 material event 行、51 家企业、322 个企业—赛道对。
- entry：41,003 个成熟候选样本、3,833 条 material event 行、51 家企业、38 个赛道。
- 最后一窗 continuation 为 307 行/129 正样本，entry 为 1,716 行/26 正样本；正样本率分别为 0.420195 和 0.015152。
- 原始设备、申报、试验 ID 不在当前环境，独立实体数及跨分区派生重复无法重算。3,833 是事件行数，不改写成独立设备数。

## 统一报告口径

每个预测方法报告：样本数、正样本数与发生率、AP/PR-AUC、Precision@K、Recall@K、0.5 阈值误报率、可计算的目标提前时间、三窗口均值/标准差、必要的配对 bootstrap 区间和公司/赛道子组稳定性。K 为评估样本的约 10%，Recall@K 由冻结 K 与 Precision@K 重算。

## S-028 / S-029 风险约束

- **实体映射**：事件缺 matched alias、置信度和规则版本；84 条事件在并购完成前归到母公司。S-029 另证实 exact-parent 查询会漏掉 67.68% 的公司提及记录，并存在人名/机构碰撞。
- **左截断**：历史从 2016-11-01 开始；S-028 的 322 个最终观测对中 230 个在首个原点前已活动。“首次”只能是窗口内首次/再出现。
- **时间代理**：历史公开时间统一为估计的 decision+14d；真实近实时观察不足。
- **重复与派生副本**：当前只有聚合产物，无法独立重放 ID 去重，不宣称完成独立重复审计。
- **跨源错误对应**：无试验→FDA 预测目标；OpenAlex 别名有噪声；采购缺首次公开时间；专利为 0 行。
- **语义映射**：当前产品代码→赛道映射没有历史版本，SQL as-of replay 无法发现这种后见之明。
