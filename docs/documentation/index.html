Quickstart

Install, test, demo, then optionally go live.

  • Install

    Standard library only; Python 3.10, 3.11 and 3.12 are tested in CI.

  • Test

    1,160 collected, 1,157 passed, 3 skipped. No network, no API key.

  • Demo

    Offline build from the committed snapshot in under 60 s: out/demo/index.html.

  • Live run

    Needs network, about three minutes, still no API key. Writes the report, the dashboard and the CSV.

source: README.md → Reproduce; PROJECT_STATE.yaml → tests; .github/workflows/ci.yml

shellverified commands
git clone https://github.com/ChazY11/medradar.git
cd medradar && pip install -e .

# 1,160 offline tests · no network · no API key
python -m pytest -q -o addopts=""

# offline demo → out/demo/index.html (< 60 s)
medradar demo

# live run → report, dashboard, summary.csv (~3 min)
medradar run --months 24 --with-trade --with-dashboard

Reading map

Four readers, four routes.

Pick the route that matches why you are here; each ends at the document that owns the explanation.

evaluator

Is any of this true?

Start with the validation status and the limitations, then read the results with their artefacts.

  • README → Validation status
  • Research page → results and limitations
  • docs/CASES.md
reproducer

Can I rebuild it?

The procedure is reproducible offline; the 1.3 GiB snapshot is not committed, so exact counts are not.

  • README → Reproduce
  • docs/METHODS.md
  • docs/SCHEMA.md
contributor

Where do I start?

The highest-value contributions are curated knowledge files — company aliases, track dictionaries, product-code mappings — not code.

  • CONTRIBUTING.md
  • docs/GOOD_FIRST_ISSUES.md
  • docs/METHODS.md
auditor

What is actually merged?

The state file is the single source of truth; the research index and the status blocks are generated from it. Branch protection is not applied.

  • PROJECT_STATE.yaml

  • docs/governance/FROZEN.yaml

MedRadar

Research infrastructure for public medical-technology evidence: one auditable event store, frozen experiments with named baselines, and negative results published at the same size as the positive ones. Not a validated predictive product.
