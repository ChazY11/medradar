# Image and figure provenance

**Policy.** MedRadar does not ship fabricated imagery. Every image in the README and on the GitHub
Pages site is either (a) generated by a committed, deterministic script from committed repository data,
or (b) a screenshot of a page the repository itself generates. There is no stock photography, no AI
image generation, no mock-up UI, and no decorative chart without a data source. If an image cannot be
traced back to a file in this repository, it must not be added.

This file records where each image comes from, how to regenerate it, and what judges it.

## Regenerate everything

```bash
python tools/homepage/build_brand.py         # mark, favicon, banner SVG, status badges
python tools/homepage/build_architecture.py  # four architecture diagrams
python tools/site/make_figures.py            # research and coverage figures
python tools/site/build_site.py              # the five site pages that use them
```

Each generator supports `--check` (exit non-zero if the committed file is stale). `tests/test_figures.py`
re-renders the figures in memory and fails when the art no longer agrees with `docs/DATA.md` or
`docs/metrics.json`; `tests/test_site.py` checks that the site pages reference the files below and that
every image carries `alt` text and explicit dimensions.

Generated by `tools/homepage/build_architecture.py` (1000×590 viewBox, ~20 KB each). The diagram is a
