# V1-001 / QUALITY REPORT — 真实样本、误报、漏报、按来源表现

> 评估等级约定：**A** = 本轮直接测量且可复算；**B** = 单一评审者的判断（方法有偏）；**C** = 引用他人文档，本轮未复验。
> 本轮**没有真实用户**，因此所有「有用 / 有价值」的判断最高只能到 B 级。

## 2. 召回通道：召回率与精确率

### 2.1 召回率（参考集 = 8 个事件，全部是监护设备安全事件）

| 指标 | 值 | 分母 | 说明 |
| --- | --- | --- | --- |
| 系统**识别**到的事件 | **8 / 8 = 1.00** | 8 | 任意视图（含历史补充） |
| 进入**正式情报**的事件 | **0 / 8 = 0.00** | 8 | 全部在窗口前公开，按策略进入历史补充 |
| 参考集中被漏掉的事件 | 0 | 8 | — |

第二个 0 不是缺陷，是策略结果：8 个参考事件的公开日期都在 2026-09-28 至 2026-10-16 之间，
而周报窗口是 2026-10-19 起。系统把它们放在「历史安全事件补充」，并且**没有**伪装成本周新闻。
这正是本轮要验证的核心语义。

### 2.2 精确率（按事件：逐条阅读了最近 28 个「监护范围内」事件）

样本是 `recall_coverage.json` 按公开日期倒序的前 28 个监护事件。判定标准：设备本身（或其测量链）是否属于监护范围。

| 判定 | 数量 | 比例 | 例子 |
| --- | --- | --- | --- |
| 明确属监护设备 | 19 | 0.68 | Philips PIC iX / Nihon Kohden CNS-6200 / GE Portrait / Masimo Radius VSM / BD ForeSight 组织血氧 |
| 边界（相关附件、治疗设备、或缺陷不在设备性能上） | 6 | 0.21 | Percussionaire IPV 呼吸治疗机、Maquet Flow-i 麻醉机、Dexcom G7（原因是失窃而非性能） |
| 明确不属于监护设备 | 3 | 0.11 | GEM Premier 血气分析仪、BD Connecta 旋塞、Flow-i 麻醉机 |

**3 条明确误判全部来自 `DEVICE_TEXT` 层级**，而且进入的是 REVIEW（不是正式情报），
因此它们污染的是「待复核队列」而不是周报。**B 级**（单评审，28 条样本）。

- 应当保留：**13 / 15 = 0.87**；
- 对监护研发**有直接行动价值**：**6 / 15 = 0.40**（第 1、6、7、10、12、13 条）；
- 明显偏弱：**2 / 15 = 0.13**（单病人房颤、加速度计吞咽）；
- 级别分布：HIGH 1 / MEDIUM 14 / CRITICAL 0 —— **不是常量，但 HIGH 偏少**，原因是本周窗口内没有新的监护召回。

## 6. 错误与不确定性（逐项）

| 项 | 状态 | 影响 |
| --- | --- | --- |
| 召回原因的后果判定是**规则**（正则）而非临床判断 | 已知 | 可能把「可能导致」类措辞判成 CRITICAL；抽检 165 条 CRITICAL 中未见明显误判，但未逐条复核 |
| 事件公开日期用的是 FDA 的 `event_date_posted` | 已知 | 与「事件发生日期」不同；两者都在条目里分别显示 |
| 召回产品记录与「我的型号是否有问题」之间的映射 | **未实现** | 用户仍需自己对照型号；这是下一阶段最值得做的能力 |
| 单例/病例报告的封顶规则 | 已实现 | 只按标题识别，标题不写 design 时可能漏掉 |
| 文献摘要缺失时的判断 | 已降级 | confidence 下调，并在理由中写明「仅按标题判断」 |
| FDA 网页可能被反爬拦截 | 已知 | 用户点「原始链接」可能看不到页面 |

## 7. 评估限制（必须与数字一起读）

1. **没有真实用户**，所以「精确率」是本项目一名评审者的判断，不等于用户判断；
2. 召回参考集只有 8 个事件、由同一人构造，是**下界**；
3. 文献通道本轮**没有**独立参考集，因此没有文献召回率；
4. 120 条既有标注是**旧规则**下的样本，不能用来评价新规则；本轮没有重标；
5. 所有比例的分母都写在表里；样本 < 30 的比例只作为描述，不作为统计结论。
