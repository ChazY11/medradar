# S-028 负结果登记 / Negative Results

**Rule of this document:** every negative result is recorded with the measurement that produced it,
its minimum detectable effect where applicable, and what it does *not* license. Nothing is deleted
because it failed. This file is the primary scientific output of round 1.

## N1 — 图结构特征不提供超越强非图基线的增量信息（主结果）

| 项 | 内容 |
|---|---|
| 检验 | H1：ΔAP(G1 − B2) > 0，H=4q 主分析 |
| 观测 | ΔAP = **−0.00609**，company CI [−0.02219, +0.00450]，pair CI [−0.03347, +0.01043]，MDE 0.01943 |
| 判定 | **NULL (well-powered)**。方向为负，区间跨零，0/3 窗口排除零 |
| 复现 | 41,003 单元 / 418 正样本；`experiment_H4q.json` |
| 不能据此说 | "网络结构对医疗技术演化无用"（一般性）；"这种图定义之外的关系也无用" |
| 可以据此说 | 在 51 家策展企业 × 38 赛道的二部图、本 target 与切分下，图特征没有提高样本外 AP；若存在收益，小于 0.019 AP |

## N2 — 真实图不优于保度+保时序随机化图（H2，决定性）

| 项 | 内容 |
|---|---|
| 检验 | H2：真实 pooled AP > 40 次保度随机化图的第 97.5 百分位 |
| 观测 (H4q) | 真实 0.06900；随机化 min 0.06919 / median 0.07432 / max 0.08198；**40/40 次随机化优于真实** |
| 观测 (H2q) | 真实 0.06704；随机化 min 0.06134 / median 0.07348 / max 0.10069；30/40 优于真实 |
| 判定 | **H2 不成立，且方向与假设相反** |
| 不能据此说 | "随机连接更有信息"（过度解读）；"关系数据无价值" |
| 可以据此说 | 在匹配了度序列与时间分布之后，"哪家企业在哪个赛道"这一安排**没有**表现出可测的额外预测价值 |
| 必须并列披露的解释 | 真实图高度不均（平均企业度 3–4），随机化摊平活动；对 L2 逻辑回归而言摊平可能更"好拟合"。因此该结果同时反映"无信息"与"学习器/尺度敏感性"，本数据无法区分二者 |

## N3 — 更强的学习器没有帮助，反而在 AP 上更差

| 项 | 内容 |
|---|---|
| 观测 (H4q) | HistGB AP 0.0567 vs 逻辑回归 0.0751（ΔAP −0.0184，CI [−0.0686, +0.0212]） |
| 观测 (H2q) | HistGB AP 0.0354 vs 0.0674（**ΔAP −0.0319，CI [−0.0959, −0.0005]，排除零**） |
| 反向指标 | HistGB 的 ROC-AUC 更高（H4q 0.7847 vs 0.7652；H2q 0.8114 vs 0.7816） |
| 判定 | **复杂模型未带来 AP 提升；在 H2q 上显著更差（AP 口径）** |
| 不能据此说 | "GNN 一定无用"（从未运行 GNN）；"梯度提升永远更差" |
| 可以据此说 | "用更复杂的模型"不是本数据的解法；且**指标选择会反转结论**（ROC 说更好，AP 说更差），必须预先声明主指标 |

## N4 — 所有预先声明的图特征组边际贡献不可与零区分

| 项 | 内容 |
|---|---|
| 观测 (H4q) | 6 个消融变体 pooled AP 0.0673–0.0734，**全部低于 B2 0.0751**；ΔAP 的 CI 全含 0；MDE 0.018–0.027 |
| 观测 (H2q) | 移除相似度/二跳组后 AP 分别 +0.0030/+0.0029，但 CI 全含 0，MDE 0.045–0.056 |
| 判定 | 无任何图特征组的正贡献可被检测；删除两组（peer-entry、similarity）反而略微提高 AP（H4q） |
| 后果 | `g_twohop_reach`（max\|r\|=0.849）与 `g_company_eigenvector`（0.779）被判定为**历史计数的近似重述**；其余特征虽有独立方差，但**不预测** |

## N5 — 赛道/企业层面的异质性不可判定（H4 失败作为"数据不足"而非"无差异"）

| 项 | 内容 |
|---|---|
| 观测 | 38 个赛道中仅 **6** 个、51 家企业中仅 **5** 家达到预声明的 n≥10/pos≥5 门槛（H4q）；H2q 仅 1 个赛道、1 家企业 |
| 判定 | **H4 不可判定**。不存在"某些赛道显著有效"的证据；也不存在"赛道有效但被稀释"的证据 |
| 后果 | 任何"在某技术领域有效"的主张在此数据上必然是事后挑选；本轮**不得**给出该主张 |

## N6 — 最强的非图基线本身也只是"弱排序"

| 项 | 内容 |
|---|---|
| 观测 | 基础率 1.019%，最强非图 AP 0.0751；P@10% 5.8%，R@10% 44.8% |
| 含义 | 每 10 个被排在最前的候选中约 0.58 个真事件；这是"有用的排序"，不是"可靠预测" |
| 不能据此说 | "可以据此做临床/监管/投资决策" |

## N7 — 校准指标在此密度下基本不可分辨

| 项 | 内容 |
|---|---|
| 观测 | 主配置 Brier 0.0124–0.0126，ECE 0.0015–0.0029；但基础率仅 1.0%，一个近似恒定的预测器也能得到极低 Brier/ECE |
| 判定 | 低 Brier/ECE **不构成**校准良好的证据；本数据密度下校准无法作为质量判据 |
| 后果 | 不得以"校准很好"支持任何模型主张 |

## N8 — 数据基础设施层面的负结果（不是模型的负结果）

这些不是 S-028 假设的失败，而是**数据无法支撑更严格研究**的证据，必须与模型负结果并列：

1. **映射不可复现**：`events` 无 `match_confidence`/`matched_alias`；8 个 (applicant, company)
   组合在无别名情况下匹配成功；2,089 条赛道赋值中 325 条无法用关键词回退复现；
   `product_codes` 表为空。（`RELATION_AND_TIME_EVIDENCE_AUDIT.md` §5）
2. **真前瞻样本几乎为零**：Live Observatory 400 条中只有 **6 条** lag ≤ 1 天；
   91.25% 的 lag > 7 天。不能用它做前瞻验证。
3. **关系类型缺失**：无企业↔企业边、无机构/论文作者数据、采购数据 100% `pit_usable=0`。
   （同报告 §3、§6）
4. **实体映射后见之明可量化**：84 条事件早于并购完成日却记在母公司名下；`bd` 有 44.11%
   的事件来自被并购别名。
5. **左截断**：71.4%（口径 A）/ 9.90%（口径 B）的对在窗口边界处已活动。
