The UN Comtrade API portal is moving

We're moving everything you use this portal for to the UN Comtrade website, so you can manage your data and your API access in one place.

What's changing:

- API keys: You'll get and manage your subscription keys on the new My API portal page of the UN Comtrade website (My Comtrade → My API portal)

- API documentation: The reference for all API products will be now on a single page: API documentation

What stays the same:

- The API endpoints and how you call them are unchanged.

- Your existing subscription keys keep working. You don't need to update your scripts or applications.

Questions? Contact us at comtrade@un.org
