# MedRadar GRAND QUESTION-001：独立科研战略报告

**日期：2026-11-14**  
**任务：独立科研方向探索，不修改代码、不创建 PR、不改写 SCIENCE-001/002/002R**  
**结论性质：战略判断，不是系统综述或新颖性保证**

## 1. Executive Summary

### 1.1 最终建议

如果由我以独立 PI 身份对未来十二个月负责，我会把主线改为：

> **首个 De Novo 类别中的 special controls，尤其临床与性能证据要求，是否影响后续独立企业进入该器械类别。**

这是一项监管科学与创新扩散研究，不再是早期预测研究。它直接承接 Aboy、Crespo 与 Stern 在 2024 年提出但未系统回答的双向机制：特殊控制可能抬高跟随者成本，也可能通过明确预期而降低监管不确定性[R27]。Johnston 等已经记录 De Novo 器械成为后续 510(k) predicate 的现象，但没有把特殊控制强度与独立进入系统地连接起来[R30]。Schumacher 等已经测量新 product code 的使用间隔，不能把“首次使用后的独占期”再包装成新问题[R28]。MedRadar 可以研究的是**为什么会扩散或为什么不扩散**。

两条备选线保留竞争关系：

1. **实体持续性与公开时间审计**：跨数据集检验早期信号研究的高分有多少来自“这是哪家企业”，而不是“这个时点发生了什么”。它是方法学副线，只有在至少两个外部公开研究或数据集上复现出相同反转，才值得独立投稿。
2. **监管类别创建与技术谱系转向**：检验新 product code 出现后，后续 predicate 引用是否真的改变，还是只给既有技术谱系换了标签。它必须先通过 predicate 抽取准确率试验，不能先建大图再寻找故事。

### 1.2 不再建议的主线

- 不建议继续把 SEC 研发投入、词频或更多公开来源堆到未来 510(k) clearance 上。SCIENCE-001/002 已经在两个结果族上显示 pooled 与 within-firm 的根本差别，继续换模型大概率仍在测企业组成[R2][R3]。
- 不建议以“论文—专利—披露—监管产品”的全链条重建为主目标。跨论文与专利的技术演化、科学—技术链接和转化预测已经相当成熟[R8][R9][R10][R12][R13][R14]。MedRadar 缺少可验证的技术概念真值、历史公开时间和稳定实体关系，全链条会把三个测量误差串联起来。
- 不建议把“新 product code 后出现多少后续 clearance”作为独立创新点。Stern、Aboy、Schumacher、Horvath 已经覆盖首入成本、后续使用、竞争进入与类别引导的理论或实证[R27][R28][R29][R31]。
- 不建议以通用 temporal KG、LLM 或 AI Agent 作为科研贡献本身。它们可以是工具，不能替代可证伪的问题。

### 1.3 最根本的判断

MedRadar 的竞争优势不在模型规模，也不在已经把很多公开数据放到一起。它真正可复用的资产是：较完整的 FDA 监管事件底座、对时间与身份语义的敏感、两轮有对照的 NULL，以及愿意让独立审计推翻自己的研究纪律。最适合它的不是再证明“公开信息能预测”，而是回答一个其他研究尚未充分回答的制度性问题：

> **监管类别及其证据要求，究竟只是记录创新，还是会改变随后谁进入、以什么技术路径进入。**

### 1.4 一年后的合理成果

基准情景下，理想成果是一篇监管科学或创新研究论文、一套 De Novo special controls 结构化数据、可复核的独立进入标签，以及一篇简短的方法学审计报告。若实体审计在外部研究上得到一致反转，可把第二项升级为独立方法论文。若 predicate 抽取试验通过，第三项可形成长期技术演化研究方向。

如果主要假设全部为 NULL，仍可能有贡献，但前提是有足够进入事件、可靠文本测量和可解释的置信区间。少量事件下的“没 significant”不构成科学发现。

## 2. 研究设计与证据边界

本报告依次做了仓库审计、领域扫描、反向先行研究检索、候选问题设计、审稿人式反驳和情景评分。文献调查覆盖科学计量学、科学发现 NLP、技术预测、创新扩散、研究转化、temporal KG、跨文档共指、医疗监管经济学、meta-research 与公开数据基础设施。额外搜索了监管经济学、创新测量和标签泄漏，避免只在用户列出的关键词里循环。

证据分为三类：

- **仓库事实**：以 GitHub 主分支及指定研究分支的实际文件为准。
- **文献事实**：以出版社、ACL Anthology、PubMed/PMC、DOI 页面和作者公开材料为准。
- **战略推断**：对新颖性、可行性和投稿前景的判断，不冒充已有结论。

“未找到更近工作”不等于“没有人做过”。本报告使用三档新颖性标记：

- **接近工作已存在**：只能做明确延伸，不能宣称新任务。
- **部分建立**：有真实缺口，但缺口边界需要预注册和复核。
- **Novelty not established**：当前检索不足以支持独立新颖性，必须先做定向查新或降低预期。

本报告没有开展大规模数据抓取、模型训练或新实验，也没有改变 SCIENCE-001/002/002R 的任何冻结结论。

## 3. MedRadar 真实资源与约束

### 3.1 主分支与草稿分支不能混用

主分支 `README.md` 与 `PROJECT_STATE.yaml` 描述的是研究基础设施，不是已验证预测产品。2026-10-31 快照含 375,378 条事件，覆盖 openFDA 510(k)/PMA/recall、ClinicalTrials.gov、SEC 8-K 和药品批准。公司键覆盖 35.2%，技术赛道键覆盖 52.4%[R1]。本地 SQLite 不入库，干净克隆能够复现程序，不能直接复现同一份数据库数字。

SCIENCE-002 位于 Draft PR #42 的 `research/science-002-cross-source` 分支，SCIENCE-002R 位于 Draft PR #43 的 `audit/science-002r-independent-review` 分支。两者不是主分支已合并成果，本报告按其实际分支状态引用[R3][R4]。

### 3.2 既有研究真正学到了什么

**SCIENCE-001** 发现，研发/技术词频不能在未来 90 天 SEC 技术交易披露上提供可靠增量能力，企业均值基线反而更强。其价值主要是识别出企业身份混杂，而不是证明披露文本永远无效[R2]。

**SCIENCE-002** 把结果换成 FDA 510(k)，采用企业固定效应后，pooled AUC 约 0.83 与企业内排序机会水平形成鲜明反差。SEC R&D 特征没有产生可检测的增量信号[R3]。这说明原问题在测量与估计对象上出了结构性问题，不只是特征不够复杂。

**SCIENCE-002R** 保留了 NULL，但发现未来结果决定样本纳入、相邻月份窗口重叠、文档数字不一致和“覆盖率”口径误用。它还实测证明 `registration_number` 是 product-code 级集合而非 filing-level 企业键，阻断原设想的 SCIENCE-003 修复路线[R4]。这提醒我们：下一项研究必须先验证测量对象存在，再设计模型。

### 3.3 可复用资产

| 资产 | 可以怎样复用 | 不能怎样使用 |

| FDA 510(k)、PMA、recall 与 product code 数据 | 全人群描述、类别生命周期、后续进入、predicate 图谱 | 把 decision date 当作历史公开时点 |

### 3.4 最缺失的能力

1. 对监管文本进行可复核、低成本的标注与测量效度验证。
2. 对“独立进入”进行时间一致的企业身份定义，而不是简单字符串去重。
3. 能够处理稀有事件、右删失、非独立类别和多重比较的统计设计。
4. 在不掌握历史公开时间时，避免point-in-time 叙事的自我约束。
5. 与监管科学、科学计量学和医学信息学审稿标准相匹配的理论建构能力。

## 4. State of the Field

### 4.1 科学与技术演化：多源已经不是缺口

科学科学的总体议程早已包括知识生产、扩散、职业、合作与预测[R5]。新兴技术研究也已有清晰的多维定义： radical novelty、增长、 coherence、潜在影响与不确定性[R6]。Small、Boyack 与 Klavans 已用直接引用和共引模型提出新兴主题，后续工作大量引入文本、专利、网络和机器学习[R7][R9][R11]。

论文与专利的联合路径也有直接先行工作。Liu 等 2024 年明确把科学论文和专利的演化路径放在统一方法里，并加入语义关系与趋势预测[R10]。因此，“把论文、专利和其他公开文本连起来”是研究配置，不是科学问题。MedRadar 若进入，只能提出新的估计对象、测量机制或反证。

### 4.2 科学到产品：引用链可以测量，产品转化不能简单等同

Ahmadpoor 与 Jones 通过专利与科学论文连接研究“science dual frontier”[R13]；Marx 与 Fuegi 系统测量专利首页对科学论文的引用[R12]。Hutchins 等已经证明，论文早期引用网络可以预测其未来是否被临床试验或指南引用，并公开了 iCite 数据路径[R14]。Hanney 等则提醒，研究到产品、政策和实践的时间 lag 具有多阶段与案例异质性[R50]。

这些工作支持两个结论。第一，知识流有可测结构。第二，被临床文章引用、被专利引用、获得监管许可和形成有临床价值的产品是不同结果。把它们压成单一“转化成功”标签，会制造构念效度问题，而不是增加信息。

### 4.3 科学信息抽取：方法成熟，可靠标签仍然昂贵

SciERC 把实体、关系和共指放到科学论文多任务框架中[R16]；DyGIE++ 用上下文 span 表示推进联合抽取[R17]；SciREX 把任务推进到全文档和 N 元关系，并明确展示人机标注成本与基线差距[R18]。Dagdelen 等证明了微调 LLM 进行结构化科学信息抽取的可行性[R19]。跨文档共指也有序列模型与跨语料泛化研究[R20]。

因此，把 LLM 用于监管文本并不构成 NLP 贡献。只有在新任务具有明确标签、强基线、时间外测试和实际错误结构时，数据集本身才可能有价值。科学概念跨源对齐若没有真值，通常只能算弱监督工程。

### 4.4 时间知识表示：valid time 与 public time 常被混用

Temporal KG 研究可以推断关系有效时间、预测未来链接，也有系统化复评显示简单时间戳模型在适当训练下可超过更复杂模型[R21][R22][R23]。但 MedRadar 面临的不只是事实何时成立，还包括研究者何时能够知道。历史 FDA decision date 不是公开时间，ClinicalTrials.gov 首次公示日期不能还原历史内容版本，SEC EDGAR 则具有较强 acceptance timestamp 与不可变档案[R1]。

这意味着“时间感知模型”不能自动带来真实 as-of 研究。公开时间不可识别时，更合理的是描述性研究、敏感性界限或前瞻观察，而不是补一个看似精确的日期。

### 4.5 医疗监管研究：product code 与 predicate 已被使用

Stern 已估计先驱器械企业相对跟随者的监管成本[R31]。Aboy 等分析全部 De Novo 请求并提出特殊控制与竞争的双向机制[R27]。Schumacher 等已经测量新 product code 的来源、使用间隔和审查时间[R28]。Horvath 用 NRY/POL 案例提出 product code 的“administrative channeling”[R29]。

Predicate network 也不是空白。Zargar 与 Carr 重建了手术网的监管祖先网络[R36]，Lefkovich 与 Rothenberg 用其分析 predicate creep[R35]，Zhu 等已将大规模 predicate citation network 用于召回预测[R34]。因此，单纯“建 predicate 图谱”不新，必须研究类别创建是否改变网络结构及其技术含义。

### 4.6 方法学元研究：泄漏和分组验证已知，领域证据仍不足

Kaufman 等早已系统化数据泄漏问题[R48]；Roberts 等讨论时间、空间和层级结构数据的验证策略[R25]；Kapoor 与 Narayanan 将泄漏与机器学习科学的可复现危机联系起来[R24]；Davis 等提醒临床标签泄漏需要结合预测节奏和使用场景，而非机械套用“不许时间旅行”[R26]。

由此，实体分组、时间切分和 persistence baseline 本身不是新算法。潜在新贡献只能是：在科学与技术创新预测这一具体文献群中，系统测量这些控制如何改变科学结论，并用外部公开研究验证，而不是只给 MedRadar 自己再做一次审计。

### 4.7 创新测量：结果指标彼此不等价

Nelson 等显示创新扩散指标可能发生遮蔽和符号化采用[R51]。Higham 等发现专利质量的不同后验结果并不一致，且因技术类型而异[R52]。Clayton 等要求用多种指标与机制理解扩散[R15]。这与 MedRadar 的 NULL 一致：510(k) clearance 是企业活动记录，不天然等于技术突破，更不等于临床价值。

当前最有价值的缺口不是“再找一个早期指标”，而是把**指标所代表的制度过程**研究清楚。

## 5. Research Opportunity Map：15 个可检验的候选科学问题

以下每项都按科学问题而非功能定义。两周验证指低成本可行性探针，不是完成研究。

### Q1：更丰富的 SEC 文本能否在企业内预测未来 FDA 监管活动？

1. **问题**：在企业—时间面板中，10-K/8-K 的具体产品与研发语义是否比历史活动提供增量信息？
2. **价值**：直接检验 SCIENCE-001/002 是否只是特征太弱。
3. **已有工作**：两轮研究已排除简单词频和 R&D 事实的可靠增量[R2][R3]。
4. **可能新颖性**：只在新语义测量有效且保持企业内估计时成立；否则是重复。
5. **数据**：SEC 全文、XBRL、openFDA。
6. **可获得性**：公开且可复现，但 FDA 历史公开时点不可恢复。
7. **最简单假设**：新文本块使企业内 AUC 增量超过 0.03。
8. **推翻**：多时期、非重叠季度和企业聚类区间覆盖零。
9. **强基线**：企业历史、季节性、披露活动、固定效应与非重叠面板。
10. **主要风险**：标签饱和、语义泄漏、 FDA 时间语义、同一负结果换模型。
11. **两周验证**：两家公司两种文本表征，只跑预注册小样本，不调参。
12. **贡献**：条件性方法改进；大概率为领域增量。  
**Gap：Type 1；Domain adaptation only — novelty may be weak。**

### Q2：论文—专利—企业披露—FDA 产品能否重建可靠的跨源技术转化链？

1. **问题**：同一技术概念跨源出现时，顺序与停留时间是否具有可重复规律？
2. **价值**：可能连接知识生产与监管产品。
3. **已有工作**：论文—专利路径、科学—技术引用和转化预测已成熟[R10][R12][R13][R14]。
4. **可能新颖性**：只有监管锚点带来新识别，而非把旧流程搬到器械。
5. **数据**：OpenAlex、PatentsView、SEC、FDA、临床试验。
6. **可获得性**：元数据公开，但 PatentsView/USPTO ODP 当前要求账户注册；技术概念真值和企业历史身份不足。
7. **最简单假设**：跨源概念对的论文→专利→监管顺序显著高于时间打乱零模型。
8. **推翻**：抽样人工核验显示链接准确率不足，或顺序对标签定义高度敏感。
9. **强基线**：分领域时间零模型、名称/引用直接链接、简单来源计数。
10. **主要风险**：把共现当转化，把术语漂移当不同技术，串联测量误差。
11. **两周验证**：盲审 100 个候选概念对，先测 precision/recall 与可判率性。
12. **贡献**：若链接可靠可做描述性转化研究；否则无。  
**Gap：Type 2；Domain adaptation only — novelty may be weak。**

### Q3：早期信号研究的表观能力有多少来自实体持续性？

1. **问题**： pooled、企业内、跨企业和时间外估计之间的差，是否系统性改变科学结论？
2. **价值**：区分“何时变化”与“哪些企业持续活跃”，直接关系到早期信号是否成立。
3. **已有工作**：分组验证和泄漏是已知方法问题[R24][R25][R48]；MedRadar 已在两个结果族观察到相同结构[R2][R3]。
4. **可能新颖性**：跨多个公开创新预测任务的效应量元分析，而非单一审计清单。
5. **数据**：MedRadar 两套面板，加至少两个带公开代码和数据的外部研究。
6. **可获得性**：内部较好；外部研究的许可、完整性和可复现性需逐案核实。
7. **最简单假设**：实体条件化使增量效应中位数下降 50% 以上，或使多数结论反转。
8. **推翻**：外部任务中 pooled 与 within-entity 结果基本一致，复杂模型仍稳定胜出。
9. **强基线**：实体均值、历史持久性、时间零模型、 grouped/time split、label transplant。
10. **主要风险**：选择最容易反转的研究，外部复现失败，估计对象改变后不可比。
11. **两周验证**：完整复现两个外部任务并冻结四种估计口径。
12. **贡献**：元研究方法、评估基准，可能是否定常见报告方式的反直觉证据。  
**Gap：Type 3 + Type 5 + Type 6；部分建立。**

### Q4：公开时间不可识别时，早期提前量能否用部分识别界限而非点估计表达？

1. **问题**：不假定唯一 FDA 公开滞后时，哪些 lead-time 或增量预测结论仍然成立？
2. **价值**：把不可观测知识时间从脚注提升为识别问题，避免虚假精确。
3. **已有工作**：PIT、时间 KG 与敏感性分析丰富，但针对监管早期信号的公开时间识别研究未充分确认[R21][R26]。
4. **可能新颖性**：对 lead time 给出在全部可接受滞后分布下的识别区间和稳健决策规则。
5. **数据**：SEC 真实公开时间、CT.gov 日期级公开时间、FDA 事件时间及前瞻观测。
6. **可获得性**：部分公开；FDA 历史公开滞后不可识别，不能借其他来源硬校准。
7. **最简单假设**：某信号在宽达 0–60 天的全部滞后设定下仍保持同号且超过基线。
8. **推翻**：结论在合理滞后区间内频繁反转，或界限宽到没有决策价值。
9. **强基线**：事件时间结果、固定滞后敏感性、极值与单调性假设下的界限。
10. **主要风险**：数学包装空信息；假设不可信；审稿人认为只是敏感性分析换名。
11. **两周验证**：在一个 SEC→FDA 小面板上推导并计算识别区间。
12. **贡献**：时间测量方法，若形式化充分可高于普通领域应用。  
**Gap：Type 2 + Type 3；Novelty not established。**

### Q5：能否构建时间一致的企业—子公司身份解析基准？

1. **问题**：在历史时点上，公开文档能否正确回答“该申请人当时属于哪个企业”？
2. **价值**：企业链接是跨源研究的基础，但当前快照会把未来所有权回填历史。
3. **已有工作**：跨文档共指和实体解析方法多[R20]，专利受让人消歧成熟；时间化法律实体标签仍难。
4. **可能新颖性**：带有效期的企业关系、跨源困难负例、禁止未来信息的评估任务。
5. **数据**：SEC Exhibit 21、FDA 申请人和 owner/operator、clearance letter、并购公告。
6. **可获得性**：公开但正例多、可证实负例少，所有权起止日期不完整。
7. **最简单假设**：时间感知模型在时间外企业上优于静态别名表且不降低精度。
8. **推翻**：静态归一化已相当，或金标准覆盖不足导致无法测量召回。
9. **强基线**：字符串归一化、静态别名、同年规则、简单学习排序。
10. **主要风险**：Ground Truth 不完整、收购日期与控制权不一致、人工标注膨胀。
11. **两周验证**：50 份 clearance letter + 20 个所有权变更案例，先验证 filing-level 链接是否存在。
12. **贡献**：新 benchmark 与测量数据；不是新预测平台。  
**Gap：Type 2 + Type 5；部分建立，但标签可行性未证实。**

### Q6：历史术语不一致时，能否可靠识别同一技术及其语义变化？

1. **问题**：跨年代、跨来源的技术提及，何时是同一概念，何时只是词面相似？
2. **价值**：这是跨源演化的前置测量任务，可独立形成 NLP 研究。
3. **已有工作**：SciREX、跨文档共指和实体链接提供强基线[R18][R20]。
4. **可能新颖性**：以监管 product code/predicate 为锚的时间化技术概念数据，而非普通共指。
5. **数据**：FDA summary、product-code 定义、专利与论文文本。
6. **可获得性**：公开，跨源真值需要人工双盲 adjudication，规模受限。
7. **最简单假设**：时间感知表示在时间外时期提高链接 F1，并减少同名异义错误。
8. **推翻**：简单 embedding/规则已相当，或人工一致性不足以形成金标准。
9. **强基线**：词面匹配、静态产品码、Sentence-BERT、共指模型。
10. **主要风险**：product code 不是纯技术概念，标签循环，模型学到来源风格。
11. **两周验证**：200 对困难样本，双人盲标并测一致性与基线。
12. **贡献**：任务与数据集；若只换领域训练分类器则创新弱。  
**Gap：Type 5；Novelty not established。**

### Q7：De Novo special controls 会促进还是抑制后续独立进入？

1. **问题**：首个类别的临床/性能证据要求与随后独立申请者的进入概率、进入时间和多样性有何关系？
2. **价值**：检验监管要求究竟形成进入壁垒，还是通过明确规则降低不确定性。
3. **已有工作**：Aboy 提出双向机制[R27]；Johnston 记录临床证据和后续 predicate 使用[R30]；Schumacher 测量 product-code 使用间隔[R28]；Stern 研究首入成本[R31]。
4. **可能新颖性**：把特殊控制内容与独立进入连接，覆盖全部可获得 De Novo，而非只描述首用间隔。
5. **数据**：De Novo granting order/decision summary、21 CFR special controls、后续 510(k)、产品码与申请人。
6. **可获得性**：官方公开；需要结构化文本和时间一致申请人去重。
7. **最简单假设**：临床性能型 special controls 与三年内独立进入率存在可检测关联，方向预注册为竞争性两种机制。
8. **推翻**：效应接近零且区间排除有实际意义的正负效应，或文本测量不成立。
9. **强基线**：年份、专科、器械类型、首创审查时间、是否有 pivotal study、类别已有活动。
10. **主要风险**：特殊控制与器械复杂度共同决定，进入事件少，因果解释过度。
11. **两周验证**：分层抽 60 个 De Novo，测文档可得性、标注一致性、独立进入事件数。
12. **贡献**：监管科学实证证据、结构化数据、对首 mover 激励的新认识。  
**Gap：Type 1 + Type 4；部分建立，是最有潜力方向。**

### Q8：新 product code 会改变后续技术谱系，还是只重新标记既有谱系？

1. **问题**：类别创建前后，predicate 的来源、跨码边、跨企业边和技术相似度是否发生系统性变化？
2. **价值**：区分监管分类的引导作用与纯记账作用，检验行政分类是否塑造技术搜索。
3. **已有工作**：Horvath 单案例提出 channeling[R29]；predicate ancestry 与召回预测已有大规模工作[R34][R35][R36]。
4. **可能新颖性**：跨类别、带对照的前后变化与谱系机制，而非单个网络或数量。
5. **数据**：510(k) summaries、predicate K-number、product code、De Novo order、申请人与文本。必须区分官方类别创建日与首次观察使用日，product-code 重分配单独标记。
6. **可获得性**：公开但历史摘要缺失、PDF 结构不一，需要高准确率抽取；当前分类文件不能无日期地回填历史。
7. **最简单假设**：新码后 predicate 社群更封闭，跨企业借用和谱系重组模式与匹配对照不同。
8. **推翻**：前后无差异，或变化由年代、专科、首创企业与网络年龄解释。
9. **强基线**：网络年龄趋势、同专科同年代对照、随机类别创建时点、product-code 计数。
10. **主要风险**：生存者偏差、缺失 predicate、反向因果、把监管引用等同真实技术流动。
11. **两周验证**：12 个新码与 12 个对照，人工核验 200 条 predicate 边并做小型前后比较。
12. **贡献**：技术演化与监管分类机制、可复用谱系数据。  
**Gap：Type 1 + Type 4 + Type 6；部分建立。**

### Q9：哪些器械与企业在公开早期证据中系统不可见？

1. **问题**：SEC、试验、论文与专利对 FDA 活动的覆盖是否与企业规模、国家、路径和产品类型非随机相关？
2. **价值**：早期信号研究的条件总体可能本身有选择偏差，影响所有后续结论。
3. **已有工作**：公开数据覆盖和 affiliation 噪声已被讨论，MedRadar 也实测低归属率[R1]。
4. **可能新颖性**：以 FDA 全量为分母，给出跨源可观察性的联合分布和上下界。
5. **数据**：FDA 全量、SEC、CT.gov、OpenAlex、PatentsView、企业注册信息。
6. **可获得性**：公开；真实母公司分母和链接召回不可完全识别。
7. **最简单假设**：可观察性随企业上市状态、规模和器械类别显著变化，且不能视为随机缺失。
8. **推翻**：在可核验链接与界限分析中，各组覆盖近似且偏差不足以改变结论。
9. **强基线**：高精度名称链接、宽/窄归属界限、随机缺失模型。
10. **主要风险**：把未链接当未覆盖， recall 不可知，隐私和商业数据库诱惑。
11. **两周验证**：分层抽 500 个申请人，人工核验 100 个链接与 100 个未链接。
12. **贡献**：测量论文和后续研究的加权/边界基础。  
**Gap：Type 2 + Type 4；部分建立。**

### Q10：不同“技术创新”定义会不会改变医疗器械研究的结论？

1. **问题**：De Novo、新 product code、首个企业—产品码、文本不相似、后续影响等指标是否测量同一构念？
2. **价值**：检验 clearance 作为创新代理的构念效度，防止指标互换。
3. **已有工作**：Aboy 区分类别与迭代创新[R27]；Schumacher 使用 novel PC[R28]；一般创新测量已显示指标不一致[R51][R52]。
4. **可能新颖性**：在器械监管全量上量化指标间不一致及对研究结论的敏感性。
5. **数据**：FDA 路径、product code、文本、predicate 后续使用、召回与试验。
6. **可获得性**：公开；没有统一的“真实创新”金标准。
7. **最简单假设**：不同指标只弱相关，并导致企业/赛道排名和早期信号结论显著变化。
8. **推翻**：指标高度一致且结论稳定，说明构念担忧不影响实质结果。
9. **强基线**：仅路径、仅新码、仅文本、仅后续使用的单指标模型。
10. **主要风险**：用多个有争议指标互相验证，循环定义，无法证明何为真创新。
11. **两周验证**：100 个分层案例做指标相关和排名翻转分析。
12. **贡献**：测量学论文或方法附录；单独成篇需要强烈反直觉结果。  
**Gap：Type 2 + Type 6；部分建立。**

### Q11：召回会改变企业随后的技术搜索方向吗？

1. **问题**：严重召回后，企业更倾向修改既有谱系，还是转向新产品码与新技术组合？
2. **价值**：研究失败反馈是否塑造后续创新，而非只预测召回本身。
3. **已有工作**：召回预测与 predicate 风险继承已有大量研究[R33][R34]，对后续搜索方向关注较少。
4. **可能新颖性**：把召回当作技术搜索事件，结合谱系变化而非活动量。
5. **数据**：recall、510(k)、product code、predicate 与申请人。
6. **可获得性**：公开，企业和产品归因部分缺失，召回严重程度异质。
7. **最简单假设**：设计相关 Class I/II 召回后，跨产品码进入率相对匹配企业上升。
8. **推翻**：变化与未召回企业、产品码趋势和召回前趋势一致。
9. **强基线**：匹配事件研究、召回前趋势、严重程度分层、普通行政召回对照。
10. **主要风险**：内生召回、企业战略共同变化、样本稀少、公开时间混淆。
11. **两周验证**：30 个严重召回与匹配对照，做预趋势和方向分类。
12. **贡献**：解释性创新研究；若只有前后活动差异则不足。  
**Gap：Type 4；Novelty not established。**

### Q12：哪些器械临床试验会转化为监管产品，哪些会消失？

1. **问题**：试验设计、赞助者和器械类型是否与后续 clearance 或长期无监管事件相关？
2. **价值**：研究转化与失败，而非只研究成功产品。
3. **已有工作**：一般转化预测和临床试验预测丰富[R14][R50]，跨注册链接已有大量应用。
4. **可能新颖性**：以器械监管结果为终点的生存分析与失败队列。
5. **数据**：CT.gov、FDA、PubMed、申请人/赞助者。
6. **可获得性**：公开；CT.gov 无历史内容版本，企业链接与试验—产品匹配困难。
7. **最简单假设**：特定设计和赞助者特征与五年转化概率存在独立关联。
8. **推翻**：关联由企业/治疗领域解释，或匹配准确率不足。
9. **强基线**：治疗领域、赞助者类型、试验规模、企业固定效应与时间零模型。
10. **主要风险**：未链接不等于失败，结果右删失，多个产品共用试验，反向选择。
11. **两周验证**：盲审 100 个试验—器械候选对，先测可链接率与误配率。
12. **贡献**：描述性转化研究；大概率为领域迁移。  
**Gap：Type 1 + Type 2；Domain adaptation only — novelty may be weak。**

### Q13：新 product code 是否普遍产生快速扩散和首 mover 独占？

1. **问题**：类别创建后进入间隔、审查时长和首用优势是否存在通用规律？
2. **价值**：原本可形成监管扩散的总体规律。
3. **已有工作**：Stern 已估计首入成本[R31]；Schumacher 已系统分析 2000–2024 新 product code[R28]；Johnston 已描述后续 predicate[R30]。
4. **可能新颖性**：只剩特殊控制、企业身份或技术谱系等机制细分，原问题本身不新。
5. **数据**：FDA 全量。
6. **可获得性**：很好，事件时间可靠，公开时间不需要用于描述。
7. **最简单假设**：首用间隔显著长于后续使用间隔。
8. **推翻**：与已有论文不一致只说明样本或定义不同，需要解释而非择优报告。
9. **强基线**：既有论文的原始口径与匹配年代/专科模型。
10. **主要风险**：直接重复，无法通过审稿新颖性。
11. **两周验证**：复现其总体分布即可，不应作为独立研究投入。
12. **贡献**：复现或稳健性附录，不适合作为主线。  
**Gap：接近工作已存在；不建议独立开展。**

### Q14：招聘文本能否提前揭示企业新技术能力？

1. **问题**：具体职责与交付物是否比历史监管活动更早显示新能力形成？
2. **价值**：招聘是潜在研发前信号，可能比正式披露更接近项目启动。
3. **已有工作**：S-031 已说明岗位职责可用，但产品关键词易误判，当前仅为草稿和初步标签。
4. **可能新颖性**：历史岗位语料与企业内新进入的严格时间研究。
5. **数据**：历史招聘、企业官网、SEC、FDA。
6. **可获得性**：历史页面和首次公开时间难恢复，存活偏差大，岗位删除与存档不全。
7. **最简单假设**：能力标签在企业内未来新赛道进入上提供增量。
8. **推翻**：时间存档不足、覆盖率选择偏差或增量不能超过企业历史。
9. **强基线**：企业固定效应、招聘总量、既有赛道、披露活动。
10. **主要风险**：把当前招聘网站快照当历史，AI 预标签当真值，选择性企业样本。
11. **两周验证**：两家企业两年存档覆盖审计，达不到完整性即停止。
12. **贡献**：若长期前瞻积累可做，但一年内难形成可信历史结论。  
**Gap：Type 2；当前不建议投入。**

### Q15：美国 De Novo 与欧盟 MDR 是否导致不同的后续技术扩散？

1. **问题**：不同监管类别的证据要求是否造成后续进入和创新路径差异？
2. **价值**：跨国监管比较可提高外部效度与政策意义。
3. **已有工作**：欧美监管比较与 Grennan/Town 的福利分析已存在[R32]。
4. **可能新颖性**：只有同一技术跨法域的可比类别与后续进入标签才能成立。
5. **数据**：FDA、EUDAMED、公告机构、CE 文件、企业产品记录。
6. **可获得性**：跨法域身份与公开历史不完整，部分数据访问受限。
7. **最简单假设**：同类技术在美国的独立进入速度与欧盟存在系统性差异。
8. **推翻**：无法建立可比类别，或法域选择与企业自选择足以解释差异。
9. **强基线**：同企业同技术跨法域匹配、年份与专科固定效应。
10. **主要风险**：制度不可比、商业数据库依赖、因果过度、语言与文本成本。
11. **两周验证**：20 个跨法域器械族，若无法匹配则立即停止。
12. **贡献**：比较监管研究；个人条件下风险过高。  
**Gap：Type 4；当前不建议投入。**

## 6. Research Gap 综合判断

真正值得保留的缺口不是“医疗器械还没被机器学习用过”，而是以下五类：

- **Type 1，未回答的问题**：special controls 的双向作用，新类别是否改变谱系。
- **Type 2，测量缺口**：公开时间不可识别、企业身份有效期、跨源可观察性和技术概念真值。
- **Type 3，方法缺口**：创新预测中的实体持续性、未来样本纳入、当前分类回填历史。
- **Type 4，被忽视现象**：监管分类本身作为创新制度，而非仅作为结果标签。
- **Type 5，新任务**：带有效期的企业身份、实体条件化早期信号评估、监管文本的结构化证据要求。

Type 6 的机会主要是反证：高 AUC 可能不代表时间信号；新类别可能不改变技术搜索；特殊控制可能不构成实际壁垒；不同“创新”指标可能互相矛盾。只有跨样本或跨任务证据充分时，这些反证才可能成为主要贡献。

## 8. Adversarial Review：五个领先方向的严厉反对意见

### 8.1 Q7：special controls 与独立进入

**反对意见。** 这可能只是把 Aboy 的理论段落做成回归。Johnston 已经给出后续竞争者数量，Schumacher 已经给出首用间隔，Stern 已经研究首入成本。如果special controls 只是按是否有临床研究分两类，贡献会非常薄。特殊控制与器械复杂程度、风险、专科、年代和首创企业资源共同决定，观察关联不能说明壁垒。独立进入还存在申请人别名、收购和子公司误判。大量新类别没有后续进入，右删失与零膨胀会让模型不稳定。

**审稿人可能的拒稿理由。** “这是描述性监管数据库分析，理论贡献与识别不足，且文本分类是研究者主观构造。”

**必须增加的证据。** 全量或明确抽样的 De Novo；预注册的 special-controls 本体，区分临床性能、非临床性能、软件/网络安全、 labeling、制造与质量体系；双人盲标子样本与一致性；三年内独立进入的明确分母；非独立专科聚类；负对照和右删失分析；只用描述性/关联性语言。若要做因果，需要外生制度变化，不能靠普通固定效应冒充。

### 8.2 Q3：实体持续性审计

**反对意见。** GroupKFold、时间切分、固定效应和 persistence baseline 都是常识。自己的两个 NULL 不构成元研究。外部论文的数据和代码可能不可复现，或者任务定义不同，pooled AUC 与 within-firm AUC 根本不可直接比较。只选择有反转的案例会构成选择性报告。

**审稿人可能的拒稿理由。** “方法已知，评估口径改变了估计对象，作者没有证明原研究的目标是部署到新企业还是同一企业未来。”

**必须增加的证据。** 先登记纳入标准和全部候选研究，不根据结果筛选；区分“跨企业部署”“同企业未来”“新企业未来”三种 estimand；保留 pooled 指标但增加企业内效应分解；至少两个外部公开任务完整复现；所有失败复现也报告；证明复杂模型在简单基线前是否有真实增量。若外部结果不反转，应降级为内部方法说明。

### 8.3 Q8：类别创建与谱系转向

**反对意见。** Predicate network 已经很成熟，product-code channeling 也有 Horvath 案例。新类别通常出现在新技术已经增长之时，所谓创建后的变化是技术成熟而非监管引导。510(k) 引用是法律与监管策略，不等于知识流或真实技术相似。历史摘要缺失和 PDF 抽取错误会系统性偏向新年代与大企业。

**审稿人可能的拒稿理由。** “网络描述替代机制识别，product code 与 predicate 定义存在内生关系，无法区分分类效应和技术趋势。”

**必须增加的证据。** 创建前至少三年的谱系历史、同专科同年代对照、随机创建时点 placebo、网络年龄校正、文本相似与 predicate 边两种独立测量、缺失机制敏感性、抽取人工金标准。结论只能是“与类别创建一致的结构变化”，除非有更强外生设计。

### 8.4 Q9：公开证据的可观察性偏差

**反对意见。** 未链接不能证明不可见，因为别名和子公司未知。上市状态又决定 SEC 是否存在，得到“上市企业更有 SEC 覆盖”是同义反复。用 FDA 全量做分母也不能解决母公司真实总数未知的问题。最终可能只是一个覆盖统计表，没有理论贡献。

**审稿人可能的拒稿理由。** “覆盖率的分母与召回均未识别，作者把链接失败误作社会现象。”

**必须增加的证据。** 抽样人工 adjudication 估计链接 precision/recall；宽/窄归属界限；把结果写成可观察性区间而非点估计；按国家、路径、产品类型与年代分层；证明偏差会改变至少一个下游科学结论。若只能得到描述表，作为数据附录而非独立论文。

### 8.5 Q5：时间化企业身份基准

**反对意见。** 这只是实体解析换到医疗企业，通用跨文档共指与受让人消歧已经很成熟。Exhibit 21 只提供部分正例，无法证明非子公司关系；clearance letter 的提交主体与母公司并非同一法律概念。大量人工标签与个人研究资源不匹配。

**审稿人可能的拒稿理由。** “任务定义混合了法定申请人、品牌、控制权和最终母公司，Ground Truth 不可靠。”

**必须增加的证据。** 先区分四类身份，不强行合并；只把所有权关系作为带有效期的任务，申请人字符串归一化作为另一任务；有日期的正负例和困难负例；静态别名强基线；时间外企业测试；标签许可与完整数据卡。50 份 clearance-letter 探针失败就停止，不应先抓取全量。

## 10. Top 3 Mini Research Proposals

### Proposal A：特殊控制与后续独立进入

**1. Research Question**  
在获得授权的 Class II De Novo 器械类别中，final granting order 所要求的临床性能证据，与三年内出现独立申请人 510(k) 的概率和时间有何关联？

**2. Why It Matters**  
首创者承担新类别证据成本，却可能让跟随者以 510(k) 进入。若特殊控制提高壁垒，首创者可能获得事实保护；若明确规则降低不确定性，它们可能促进扩散。这个结果直接影响创新激励和监管设计，而不仅是预测企业活动。

**3. Closest Existing Work**  
Aboy 等提出并举例讨论双向机制[R27]；Johnston 等记录 63 个治疗性 De Novo 的临床证据及后续竞争产品[R30]；Schumacher 等测量新码首用与复用间隔[R28]；Stern 估计首入监管成本[R31]。本研究的区别是以**final special controls 的内容**为解释变量，以**独立进入**为结果，做全样本关联分析。

**4. Hypothesis**  
预注册两个竞争机制，不以结果选方向：壁垒机制预期临床性能型要求降低独立进入 hazard；明确性机制预期其提高 hazard。首创者自身的后续 510(k) 用作机制对照：若要求只阻挡独立竞争者而不影响自身后续产品，更符合壁垒解释。

**5. Data**  
主队列纳入 2011–2022 年有公开 decision summary/granting order 的 Class II De Novo，随访至 2026 年，保证每例至少三年；2023 年案例仅作补充敏感性分析，不强行计入三年主队列。字段包括 DEN/K-number、product code、申请人、专科、日期、direct/post-NSE、审查天数、器械类型、final special controls、后续 510(k) 与申请人。公开官方来源可合法复现[R41][R42][R43]。最终 special controls 与申请人提议必须分开，不能从 final order 推断首创者主观策略。

**6. Method**  
建立六级证据本体：临床性能、非临床性能、软件/数据/网络安全、 labeling/使用限制、制造/质量体系、其他。先盲于后续结果标注，再链接后续活动。主分析用离散时间进入模型，product-code 类别为风险集，专科聚类；控制年份、direct/post-NSE、器械类型、首创审查天数、是否有 pivotal study 与首创者历史活动。报告 hazard ratio、三年风险差和区间，不只报 p 值。

**7. Baselines**  
只看年份/专科的零模型；只用是否有 pivotal clinical study 的模型；只用首创审查时间的模型；product-code 总体热度模型；首创者自身后续进入模型。若 special controls 不能提供超出这些简单模型的解释增量，不宣称机制。

**8. Experimental Design**  
文档抽样先于结果分析冻结；至少 20% 双人盲标，报告 Krippendorff’s alpha 和各类别混淆。申请人采用三级口径：严格字符串归一、经 adjudication 的申请实体、带日期母公司敏感性。主结果是关联，不用“导致”。对无后续进入类别右删失；对年代与专科做分层和交互；对 2018 年前后做时间外复验；对缺失 decision summary 单独比较，避免可用性偏差。

**9. Falsification**  
以下任一情况都削弱或终止：独立进入事件不足以估计；special-controls 标注一致性低；效应在不同身份口径下反转；关联完全由专科/年份解释；区间显示只有很小的实际效应且研究有足够精度。若只能得到宽区间，应报告不可判定，而不是 NULL。

**10. Minimum Viable Experiment**  
两周内按年代、专科、是否有后续进入分层抽 60 例。先核验文档可得性与 special-controls 可判性，再链接后续 510(k)。20 例双盲复标，200 个后续申请人关系人工核验。进入全量的门槛：文档可用率 ≥90%，关键字段抽取 precision ≥90%，标注 alpha ≥0.67，且进入事件数足以支持简化模型。未达标先修测量，不扩大样本。

**11. Potential Contribution**  
对“special controls 是否构成进入壁垒”给出可复核证据；发布 De Novo 证据要求数据与独立进入标签；区分首创者自身迭代与竞争者扩散。贡献不需要新算法。

**12. Publication Landscape**  
优先考虑 *npj Health Systems*、*npj Digital Medicine*、*Journal of Law and the Biosciences*；若理论与识别更强可考虑 *Research Policy*；简洁而稳健的全样本结果可考虑医学监管研究快报。ACL/KDD 不合适，除非另行产生具有通用方法创新的文本任务。不能承诺顶会水平。

### Proposal B：实体持续性与时间有效性的跨研究审计

**1. Research Question**  
在公开的医疗技术创新预测任务中，复杂模型的增量能力有多少在实体条件化和公开时间修复后仍然保留？

**2. Why It Matters**  
如果 pooled 指标主要反映企业差异，文献中的“早期信号”就可能回答错问题。统一审计能区分企业组成、历史持久性和真正的时间变化，并给出适合不同部署情景的估计对象。

**3. Closest Existing Work**  
一般泄漏与结构化验证已有成熟框架[R24][R25][R26][R48]；temporal KG 的统一复评也证明严格基线可反转模型排名[R22]。MedRadar 的两个 NULL 只提供内部动机[R2][R3]。差异是对多项独立创新预测研究做预登记的效应量比较，而不是再写一份审计清单。

**4. Hypothesis**  
复杂模型相对持久性基线的增量效应，在实体条件化后中位数下降至少 50%，且至少一半任务的结论发生实质变化。该阈值是研究设计选择，不是既有事实。

**5. Data**  
内部使用 SCIENCE-001/002 与 reverse-R&D 的冻结面板。外部至少纳入两个有公开数据、代码、许可和原始时间语义的研究；候选包括 predicate recall 与公开技术趋势任务，但必须先验证可复现性，不能在 proposal 阶段假定成功。所有候选在分析前登记。

**6. Method**  
建立三种 estimand：同企业未来、新企业未来、跨企业组成。每个任务保留原模型，重算 pooled、企业内、leave-one-entity-out 与时间外指标；分解总效应为企业均值、历史持久性和内容增量。公开时间不可恢复时只做事件时间描述或界限，不补造 PIT 标签。

**7. Baselines**  
总体 prevalence、实体均值、pair/base-rate、历史活动、随机标签、label transplant、简单逻辑回归。复杂模型必须击败同任务同切分下的持久性基线，而不是只击败随机猜测。

**8. Experimental Design**  
纳入标准在看结果前冻结；失败复现纳入报告；保持原特征与原模型，避免用“修复”名义升级方法；对月份重叠采用非重叠季度或 block shift；对样本纳入只用预测时点前信息；同时给出 pooled 指标，防止把不同部署问题混为一谈。

**9. Falsification**  
若外部任务没有一致的效应下降，或复杂模型在企业内仍稳定胜出，则强假设被推翻。若不足两个外部任务能完整复现，本方向不独立成文。若 pooled 与 within-entity 是不同 estimand 而不可比较，应改为方法说明而非“文献反转”。

**10. Minimum Viable Experiment**  
两周内完整复现两个外部任务，加两个内部任务，统一四种评估口径与三个基线。只在开发期看效应方向，之后冻结完整候选集与报告规则。若外部代码/数据缺口无法解决，立即降级。

**11. Potential Contribution**  
给出创新预测中实体持续性效应量的跨任务证据、统一评估实现和可复用审计数据。其价值是纠正科学解释，而不是发明 grouped CV。

**12. Publication Landscape**  
若有多任务、公开标签和强基线，可考虑 *NeurIPS Datasets & Benchmarks* 或 KDD 应用数据集方向；更现实的是 *Quantitative Science Studies*、*Scientometrics*、*JASIST* 或医学信息学期刊。若没有跨任务数据产品，ACL 主会不匹配；NeurIPS 也不应仅靠审计叙述投稿。

### Proposal C：监管类别创建是否改变技术谱系

**1. Research Question**  
新 product code 创建后，后续 510(k) 的 predicate 社群结构是否相对匹配对照发生系统变化？

**2. Why It Matters**  
监管分类可能不仅记录技术边界，还通过 predicate 要求引导企业的技术搜索和组合方式。验证或否定这一机制，可以把监管科学和技术演化连接起来。

**3. Closest Existing Work**  
Horvath 在 NRY/POL 中提出 administrative channeling[R29]；Lefkovich 与 Rothenberg 分析 Da Vinci 的 predicate creep[R35]；Zargar 与 Carr 构建手术网祖先网络[R36]；Zhu 等用大规模网络预测召回[R34]。本研究不重复建网，而是做跨类别、带对照的前后结构比较。

**4. Hypothesis**  
新码创建后，后续申请的同码 predicate 比例上升，谱系社群更封闭；同时跨企业 predicate 借用与文本组合模式发生不同于对照的变化。若只出现网络年龄和年代趋势，则 channeling 不成立。

**5. Data**  
2006–2023 年具有足够前后窗口的新 product code、510(k) summaries、De Novo orders、predicate K-number、申请人、产品码与文本。分析前冻结“官方创建日”与“首次观察使用日”两种口径，重分配码单列，不混作技术类别诞生。公开数据可复现，但早期摘要缺失和格式差异必须单独建模[R35][R41][R43]。

**6. Method**  
先抽取并核验 predicate 边，再计算同码边比例、跨企业边比例、predicate 年龄、来源熵、模块度、重复祖先比例和文本相似度。采用同专科、同年代、相近网络年龄的对照类别，比较创建前后变化；以随机创建时点和未变化类别作 placebo。

**7. Baselines**  
仅 product-code 活动量、仅网络年龄趋势、无创建事件的同类类别、随机时间、静态文本相似度。不能只用创建前后均值证明效应。

**8. Experimental Design**  
创建前至少三年历史用于预趋势；类别和年代聚类；缺失摘要按年代与申请人类型比较；predicate 引用与技术相似分别报告，避免把法律引用当知识流；主结论限定为“与类别创建一致的结构变化”，不直接称因果。

**9. Falsification**  
若对照类别有相同变化、预趋势已存在、随机时点产生同等效应，或结论对缺失机制敏感，则 channeling 被削弱或否定。如果抽取覆盖不足，不能据不完整网络推断。

**10. Minimum Viable Experiment**  
选择 12 个新码与 12 个匹配对照，抽取约 200 条 predicate 边做双人金标准，检查每类至少三年前后历史。进入门槛：边抽取 precision ≥95%、recall ≥90%，至少 8 对类别具有可评估历史。随后才扩大 PDF 处理。

**11. Potential Contribution**  
首次跨类别量化 product-code 创建与谱系结构的关系，形成可复用 predicate 数据与测量方法。若结果为 NULL，可约束 Horvath 单案例的一般性。

**12. Publication Landscape**  
可考虑 *Research Policy*、*Scientometrics*、*Journal of Informetrics*、*JASIST*、*PLOS ONE*；若发布高质量图谱与任务，可评估 *NeurIPS Datasets & Benchmarks*。若没有新抽取任务或通用网络方法，ACL 主会和 KDD 主会并不自然。

## 11. 12-Month Strategy

### 11.1 资源原则

全年只允许一条主线和一条副线。Q7 是主线；Q3 与 Q8 通过探针竞争副线。不得因为新数据容易获得就新增方向，不得先做全量抓取再补研究问题。本地 GPU 主要用于文本结构化与基线，不安排大模型训练。

### 11.2 阶段安排

| 时间 | 工作 | 必须交付的证据 | 决策 |
|---|---|---|---|
| 第 1–2 周 | Q7 60 文档探针；Q3 两个外部复现启动；Q8 200 条 predicate 边金标准 | 文本可得性、标注一致性、外部代码清单、边抽取准确率 | 任一方向测量不达标即停止 |
| 第 3–4 周 | 完成三个最小实验；冻结 Q7 全量协议与候选研究登记 | MVE 报告、效应可识别性、power/事件数、排除清单 | 只保留一条副线 |
| 第 2 月 | Q7 全量文档结构化与独立进入标签；Q3/Q8 副线补数 | 数据卡、标注手册、版本化样本、负例与缺失清单 | 进入全量分析的正式 gate |
| 第 3–5 月 | Q7 主分析与独立复核；副线限每周一天 | 主结果、敏感性、身份口径、时间外复验 | 若主估计不可识别，停止因果叙事 |

| 第 7–9 月 | 副线主实验与稳健性 | 外部复现/谱系对照、全部失败记录 | 是否形成第二篇论文 |
| 第 10–11 月 | 两篇稿件、数据与代码开放、第二轮反方审查 | claim-evidence map、许可、复现说明 | 不再加入新研究问题 |

### 11.3 明确放弃规则

- **测量放弃**：special controls 无法可靠分类，predicate 抽取不达标，企业身份无法形成有效期标签。
- **信息量放弃**：进入事件或外部任务不足以支持预注册的区间精度，继续加模型也无法解决。
- **新颖性放弃**：出现更近论文已回答同一估计问题，只能转为复现或附录。
- **解释放弃**：结果只支持普通年代趋势、企业持续性或专科差异，不再包装为监管机制。
- **组合放弃**：若 Q7 需要超过两个月才能获得可信标签，暂停副线，不让三条线互相拖延。

## 12. Final Independent Recommendation

### 12.1 我选择什么

选择 Q7：**De Novo special controls 与后续独立进入**。Q3 作为方法副线，Q8 只在 predicate 测量通过后启动。

### 12.2 最根本的理由

这是一个重要、具体、尚未被同口径回答的问题。它不要求 MedRadar 证明公开信息能预测未来，也不要求重建无法验证的技术转化全链条。它有官方结果、明确文本、可反驳的双向机制，并能在一年内形成可靠证据。即使结果为 NULL，只要精度足够，也能约束“特殊控制必然形成壁垒”的理论。

### 12.3 为什么不是其他方向

- Q2 的跨源链条科学意义大，但概念真值与身份误差在个人条件下不可控，而且先行研究密集。
- Q3 最契合既有 NULL，却依赖外部复现，独立贡献尚不确定，因此不宜自动成为主线。
- Q8 的长期特色强，但抽取和反事实难度高于 Q7，适合作第二步。
- Q4 理论上限高，却可能只能得到“无法识别”，风险不适合承担全年主线。
- Q5/Q9 是重要测量基础，但分母与负例问题使其更适合支撑研究，而不是优先独立成篇。
- Q13 已被 2025 年工作显著覆盖，Q1/Q14 则是在既有薄弱资产上继续加码。

### 12.4 最可能得到的新科学认识

我们将知道，De Novo 的临床与性能要求是否真正影响后续独立进入，影响有多大，是否只存在于软件/数据密集型器械，以及这种关系是否能被专科、年代和器械复杂度解释。首创者自身后续产品与竞争者产品的对照，可以进一步区分“规则明确化”与“竞争者壁垒”。

### 12.5 最大失败风险

不是模型表现不好，而是**估计对象不可信**：special controls 标错、独立企业认错、后续进入太少，或所有关联都被器械复杂度吸收。另一个风险是把 final FDA 要求误读成首创者主动设计的护城河，产生超出数据的战略叙事。

### 12.6 已有的独特优势

MedRadar 已有 FDA 全量事件、product-code 映射、申请人与企业审计经验，不需要从商业数据库起步。两轮 NULL 让其知道 pooled 高分的陷阱，SCIENCE-002R 让其知道先验证字段语义再建模。相比从零开始的团队，这能显著降低数据与审计成本。

### 12.7 最重要且仍缺失的能力

监管文本的测量效度与时间一致的企业身份，而不是更强的 GPU。还需要一名能复核临床/性能证据语义的领域审阅者，哪怕只复核分层子样本。没有这个角色，AI 预标签只能当辅助，不能自动成为 Ground Truth。

### 12.8 最快检验判断的实验

60 个 De Novo 的分层探针。它能在两周内回答文档是否存在、special controls 能否盲标、后续进入是否足够、申请人能否去重四个决定性问题。若这四点不成立，全年方向应立即改变。

### 12.9 什么时候果断放弃

- 两周后文档可用率或抽取准确率不达标，放弃原设计，先修测量。
- 两个月后仍无法定义独立进入或事件数不足，放弃独立进入主假设，不改为随意寻找显著性。
- 外部复现始终不足两个任务，放弃 Q3 独立论文。
- 对照显示类别创建效应只是年代趋势，放弃 Q8 的 channeling 强叙事。
- 出现直接覆盖同一文本—结果关系的更近研究，转为复现，不坚持“首次”。

### 12.10 一年后的理想成果

一项全样本 De Novo special-controls 数据与论文，一套独立进入标签和可复现分析；一项外部任务实体持续性审计；若 Q8 通过，再有一项跨类别谱系研究。成果应以其他研究者能否复核和讨论来评价，而不是以平台功能、数据规模或模型数量评价。

### 12.11 如果全部得到 NULL，是否仍有贡献

**Q7 可以有。** 如果有足够事件、可靠测量和排除实际效应的区间，证明 special controls 与独立进入无关，会直接约束现有理论。  
**Q3 通常不可以独立成文。** 没有跨任务反转，只能说明 MedRadar 内部审计纪律有效。  
**Q8 可以有但更难。** 需要证明研究对合理结构变化有足够检出力，否则“没看到变化”只是数据不足。  
如果所有研究都只是低功效、标签不清和宽区间，则不能靠 NULL 包装科学贡献，应承认方向尚未成立。

## 13. 最终项目定位

**MedRadar studies regulatory category creation, special controls, and predicate ancestry to understand when medical-device regulation merely records innovation and when it changes who enters and how technologies evolve.**

中文对应：MedRadar 研究监管类别的创建、特殊控制与 predicate 技术谱系，以理解医疗器械监管何时只是记录创新，何时会改变后续进入者及技术演化路径。
