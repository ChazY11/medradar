# B-030 — a lawful point-in-time hiring signal: obtained, measured, currently too thin

Generated by `write_report.py` from `hiring_panel.json` and `lag_analysis.json`; no number is typed by hand. Source selection, proxy definition and analyses were pre-registered in DECISIONS D-028 before any association was computed.

## Why this was attempted

Six cycles established that the regulatory filing lane cannot support the programme's questions: ~0.2 events per cell-month, no independent confirmation source until B-040, and every clustering claim dissolved under its own control. The declared next step was a **denser independent signal** — hiring — collected with genuine historical point-in-time availability.

## Source selection, measured

| candidate route | probe result |
|---|---|
| PatentsView bulk (S3) | **403 Forbidden** — credentials required; patents stay blocked |
| Common Crawl index API | **persistent 504 Gateway Time-out**, even for `example.com` |
| **Wayback Machine CDX** | **works, keyless**, and archives real job-posting URLs (Medtronic's `jobs.medtronic.com/job/*` alone has 15 index pages) |

The Wayback route was adopted: public web archive, **index only** (no page content fetched), bounded pages and rate-limited queries. Its key property for this programme is that the archive predates the analysis by years, so the signal is genuinely historical rather than reconstructed by our own collection.

## The proxy

* distinct job-posting URLs whose earliest archive capture falls in a month.
* Window 2014–2026; ≤16 index pages per pattern; 1.0 s between requests.
* It is a **posting-flow proxy, not headcount**: it counts postings the archive happened to capture, so archive coverage, URL-scheme stability and crawl cadence all enter the signal.

## What was achieved, and what is missing

**Achieved.** A lawful, keyless, genuinely historical hiring proxy; a bounded and rate-limited collector; a committed panel artifact; and a measured coverage map. That is the first time this programme has a real independent hiring signal in hand rather than a declared gap.

**Missing, and why it blocks inference:**

* **Domain discovery.** Several focus companies returned nothing because their career sites live on hosts the patterns did not guess (Philips, GE HealthCare, Dräger, Mindray, Abbott, Zimmer Biomet, Masimo, Hologic). Fixing this is a per-company domain problem, not a statistical one.
* **Archive depth.** Medtronic's index has 15 pages; the collector now pages up to 16, but capture cadence still varies by year, so a monthly series mixes hiring with crawling.
* **Platform changes.** Career sites migrate between posting-URL schemes; a migration creates a level shift that is a collection artifact. This must be detected per company before any level-shift analysis.

## Verdict

B-030 is a **feasibility partial**: the source exists and is lawful, the pipeline works, and the coverage is not yet sufficient for the company-level lag question it was built for. The honest next step is coverage completion (per-company career-domain mapping, platform-change audit), and only then the pre-registered lag test — which remains unrun rather than run and misreported.
