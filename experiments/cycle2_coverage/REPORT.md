# Cycle 2 — Coverage, power, and the reality of the entry signal

Generated by `experiments/cycle2_coverage/write_report.py` from the frozen artifacts in this directory; no number below is typed by hand.

## 0. What this cycle asked and what it found

**Pre-registered question** (`research/CYCLE2_DESIGN.md`): is the weak cycle-1 entry signal limited by *measurement coverage* — too few firms, too few positives — or by *the world*?

**Answer (P2 = deterministic legal-entity panel):** expanding from 51 curated parents to a 200-entity legal-entity cohort (193 with observable activity) raises holdout positives from 78 to 140 across the same three pre-declared windows, and changes the inference from *cluster-dependent* to *robust*:

- **P1 ΔAP** = 0.056446 with entity-cluster CI [+0.005350, +0.103630] (se 0.025257, clusters 51); the **pair-cluster** CI [-0.018239, +0.145578] (se 0.040431, clusters 1729) — not robust to the clustering choice; MDE(80%) = 0.070761 exceeds the observed ΔAP.
- **P2 ΔAP** = 0.097321 with entity-cluster CI [+0.042609, +0.169722] (se 0.031300, clusters 192) and pair-cluster CI [+0.049106, +0.158317] (se 0.027715, clusters 6914) — both exclude zero; MDE(80%) = 0.087689 is **below** the observed ΔAP.

So the cycle-1 negative was partly a **coverage** artefact, not purely a statement about the world. The effect is modest and the panels differ in composition, so this is a measurement finding about *resolvability*, not a claim that corporate technology entry is strongly predictable.

## 4. Pre-registered decision rule

Rule (`research/CYCLE2_DESIGN.md`): a signal is SUPPORTED if the cluster CI on ΔAP excludes zero in a majority of pre-declared windows **and** pooled CIs exclude zero under both clustering choices; a WELL-POWERED NEGATIVE if the point estimate lies inside the MDE with no CI excluding zero; otherwise STILL UNDERPOWERED.

- P1: entity clusters exclude zero in 2/3 windows (deltas [0.057622, 0.047783, 0.072649]); pair clusters in 1/3 windows (deltas [0.057622, 0.047783, 0.072649]).
- P2: entity clusters exclude zero in 3/3 windows (deltas [0.058165, 0.118931, 0.149265]); pair clusters in 3/3 windows (deltas [0.058165, 0.118931, 0.149265]).
- Pooled CI excludes zero — P1: entity True, pair False; P2: entity True, pair True.
- Pre-registered support condition satisfied — P1: **False**, P2: **True**.

**Outcome:** the P2 panel **meets** the pre-registered support condition and the P1 panel does not. Under the rule as written, the cycle-1 configuration is **underpowered** and the expanded panel is the configuration in which the effect becomes resolvable.

## 7. Negative results and what did not improve

- **No new data source was added in this cycle.** The cycle-1 nulls about financial, market and publication features are neither confirmed nor overturned here; the MDE table shows why they were weak evidence (design-stage MDE for a 26-positive window is ≈0.39, roughly 50× the +0.008 financial marginal).
- **The effect is not large.** P2 AP is 0.129189 at a 0.68% base rate: useful ranking, not a reliable per-company prediction.
- **The model is worse than the baseline on some windows in P1** and the pooled P1 pair-cluster interval includes zero.
- **The improvement is partly the baseline getting worse.** Persistence AP falls from 0.044614 (P1) to 0.031868 (P2); the model AP rises much less.
- **Entity granularity is not resolved.** P2 is legal-entity granular, so a corporate parent's activity is split across subsidiaries (Medtronic = 30 entities). A true parent panel requires acquisition chains, which this work does not build.
- **The pre-declared heterogeneity stratification failed** (degenerate on both panels; see §6). Mission question 6 is therefore still unanswered.
- **No earlier-warning effect was found.** At matched false-alarm rate the model detects more entries but not earlier ones; lead-time deltas are negative in four of six windows.

## 8. Limitations

- The two panels differ in composition, not only in size: P1 is 51 hand-curated large parents; P2 is a 200-entity activity-ranked cohort including smaller firms. The comparison is therefore *panel definition*, not a clean power experiment with everything else fixed.
- Cohort eligibility uses the universe module's `n_material` (510(k) + original PMA, supplements excluded) while panel labels use the frozen target rule (which also counts PANEL TRACK supplements). The label rule is a superset; the difference is small but it means eligibility and labelling use different definitions.
- Material events are 510(k) clearances plus a small number of original PMAs (only ~344 original PMAs exist in the lane); a regulatory milestone is a lagging proxy for R&D, not R&D start.
- `track_id` is missing for a substantial share of lane events (17,308), so entity activity that cannot be mapped to a technology is invisible to the panel.
- Three overlapping holdout windows are not independent replications; the pooled analysis uses cluster-robust inference but within-window label overlap remains.
- The knowledge clock is `decision_date + 14 days` (estimated) for the bulk lane; it is an assumption about publication, not a measurement.
- Entity resolution is deterministic string normalisation, not ground truth: typos stay separate entities and subsidiaries of one parent stay separate unless their normalised names coincide.

## 9. Explicit non-claims

- Not a causal market→R&D mechanism.
- Not a validated product: at 0.68% prevalence the ranking is weak in absolute terms.
- Not industry-representative: 200 entities from one lane, one sector.
- Not calibration evidence: no forecast has matured.
- Not evidence that any deep/complex model helps; only a linear baseline was run.
